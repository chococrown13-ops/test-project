# 도시의 나이테 · 원래 ○○이었다 #15 「선유도는 원래 섬이 아니라 산이었다」 — 기획안 (기준일 2026-11-13)

한 줄: 한강 위 섬 공원 선유도는 원래 강가에 솟은 봉우리 「선유봉」(신선이 노닐던 봉우리)이었다. 겸재 정선도 그림으로 남긴 이 봉우리는 일제강점기부터 돌을 캐 가며 깎여 나갔고, 1978~2000년엔 서울 서남부에 수돗물을 보내는 정수장이었다가, 2002년 정수장 시설을 살린 국내 첫 재활용 생태공원이 됐다.
(대표 선정 2026-11-13, 트렌드 카드 trend-20261112 C · 건강·의료 아님 · "사라진 것" ★)

- 지도 바탕 명령(제작 때, 좌표는 제작 때 확인): `python3 gunggeum/tools/basemap.py gunggeum/devlog/seonyu/map --center 37.5430,126.8990 --zoom 16 --size 2200x2800 --place "선유도역" --place "당산역" --place "양화대교" --place "선유교" --area "선유도공원"`
- 이번 편만의 연출(반복 피하기): 위에서 본 지도 → 카메라가 **옆으로 눕혀 강 높이에서 본 옆모습**으로 바뀌어, 봉우리 실루엣(약 40m)이 장면마다 깎여 내려가는 "높이 막대"를 보여 줘요. 색: 옛 봉우리 = 먹빛 산수화 톤(종이 바탕 `paper`), 깎인 부분 = 점선 윤곽, 정수장 = 청록 수조 네모, 공원 = 초록. 높이 숫자 막대 옆에 "(전해짐)" 꼬리표.
