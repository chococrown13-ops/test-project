# 트렌드 데스크 — 「오늘 뭐 만들까」 (매일 오후 4시, 2026-11-10 대표 요청)

대표님은 고르기만 해요. 우리는 **실제 숫자(시간당 조회수)** 를 근거로, **우리가 0원으로 만들 수 있는 것만** 추천해요.

## 1. 자료 모으기 (돈 안 듦)
```
python3 gunggeum/tools/yt_trends.py > /tmp/trends.json          # 한국 인기 급상승(분야별) + 48시간 쇼츠 검색
python3 gunggeum/tools/yt_trends.py --md > gunggeum/trends/<YYYY-MM-DD>.md
python3 gunggeum/tools/yt_stats.py > /tmp/ours.json             # 우리 채널(도시의 나이테) 편별 조회수
```
- 키는 Network secrets(www.googleapis.com) — 키 값은 출력·파일·커밋 금지. 실패하면 오류 이유만 적고 카드에 "자료를 못 받았어요"로 남김(지어내지 않기).
- 필요하면 WebSearch로 요즘 쇼츠 유행 형식을 한두 번 더 확인(기사·공식 블로그). 개인 추측은 "추측"이라고 씀.

## 2. 분석 (`gunggeum/trends/<날짜>.md` 아래에 「분석」으로 덧붙임)
- **형식별로 묶기**: 시간당 조회수 상위 한국어 쇼츠 30개를 형식으로 분류 — 예: 예능·드라마 잘라 올리기 / 스케치 코미디 / 썰·사연 애니 / 역사·상식 / 실험·챌린지 / 동물 / 음식 / 스포츠 하이라이트 / 키즈 동요 / 해외 말 없는 쇼츠(시뮬레이션·만족 영상·DIY).
- 각 형식: 몇 개, 시간당 조회수 중간값, 대표 영상 링크 1~2개.
- **우리 숫자와 비교**: 우리 편 중 잘된 것/안된 것과 무엇이 다른지 한두 줄.
- **우리가 못 하는 것은 빼기**: 남의 방송·드라마·뮤직비디오를 잘라 올리는 것(저작권), 실제 사람 얼굴·목소리 흉내, 유명인 사칭, 돈 드는 도구.

## 3. 추천 3~5개 (오늘 만들 영상)
각 추천은 아래를 다 채워요.
- **계정**: 도시의 나이테 / 30초 한판 / **물리 시뮬레이션 계정**(2026-11-10 결정: 구슬 레이스·골드버그 장치 등 물리 현상, `channels/physics/`, 본보기 `r01/` — 코스는 `course.js`, matter-js)
- **첫 1초 문장**(제목) · **왜 지금**(근거 영상 링크 + 시간당 조회수) · **만드는 법**(코드 그림 `render(t)` · 실제 지도 `tools/basemap.py` · 물리 시뮬레이션 · 배경음 numpy · 목소리가 필요하면 Google Cloud TTS 무료 한도 안 — 모두 0원) · **주의**(사실 확인 필요, 키즈 표시, 저작권)
- 사실이 들어가는 추천은 공식 기록으로 확인 가능한지 미리 한 번 검색해 보고 "확인 가능/어려움"을 적어요.
- 같은 형식만 반복하지 않게: 어제 카드(`strategy/trend-<어제>`)의 추천과 겹치면 바꿔요.

## 4. 사무실에 올리기 (시각은 `date -u +%FT%TZ`)
- db `strategy/trend-<YYYYMMDD>` = `{title:"오늘 뭐 만들까 · <M월 D일> 오후 4시", at, status:"결재 대기", agenda:[{id:"a1", question:"오늘 어떤 영상을 만들까요?", options:[{key:"A", name:"<계정> · <첫 1초 문장>", pros:"왜 지금(근거 숫자)", cons:"주의·확인할 점", cost:"0원", ceoWork:"고르기 → 결재 → 업로드"}…], recommend:"<key>", why:"한두 줄", sources:[근거 영상·기사 링크]}]}` → 사무실 「전략 회의실」·「대표 할 일」에 떠요.
- 같은 날 카드가 이미 있으면 새로 만들지 않고 update.
- log 한 줄: "오후 4시 트렌드 추천 n개를 전략 회의실에 올렸어요 — 골라 주세요".
- `gunggeum/trends/<날짜>.md` 커밋 → `git pull --rebase` → 브랜치 `claude/sns-account-strategy-h9eu1q`에 푸시.

## 5. 대표님이 고르면
"트렌드 <키> 해줘" / "A로 만들어" → 그 계정의 제작 라인으로: 도시의 나이테는 city-line(기획 → 결재함), 30초 한판·새 계정은 `channels/<계정>/` 시범 방식(코드 영상 → 자료실). 카드는 `status:"결정 완료", decision:"<키>"`.

## 하지 않는 것
업로드·계정 만들기·결제, 남의 영상 내려받기, 키 출력. 보고는 쉬운 한국어로 짧게.
