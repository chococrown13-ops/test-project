# 치이카와 키우기 (CHIIKAWATCH)

다마고치 감성의 모바일 웹 육성 게임. 빌드 도구 없이 `index.html` 파일 하나로 동작합니다.

## 실행

파일을 브라우저로 열기만 하면 됩니다.

```bash
python3 -m http.server 8080   # http://localhost:8080/chiikawa/
```

폰에서는 Safari/Chrome으로 열고 **홈 화면에 추가**하면 주소창 없이 전체화면으로 실행됩니다.

## 조작

- **A** 아이콘 이동 / 목록 커서 이동
- **B** 결정
- **C** 취소 (한 칸 뒤로 이동)
- 아이콘과 화면을 직접 탭해도 됩니다. 캐릭터를 탭하면 쓰다듬기(행복·친밀도 +).

## 규칙

| 아이콘 | 하는 일 |
| --- | --- |
| 밥 | 풀(공짜) 또는 사둔 음식을 먹입니다. 먹으면 잠시 뒤 똥이 나와요. |
| 놀기 | 좌우 맞히기 3판. 2승 이상이면 행복 +26, 10G. |
| 토벌 | 15초 동안 요괴를 탭해 골드를 법니다. 연속으로 잡으면 보너스. 체력 소모 큼. |
| 청소 | 똥을 치웁니다. 2개 이상 쌓이면 병에 걸릴 확률이 올라가요. |
| 불 | 불을 끄면 잠을 잡니다(체력 회복). 자는 도중에 켜면 돌봄 실수. |
| 약 | 아플 때 약을 먹입니다. 약은 가게에서 삽니다. |
| 상태 | 능력치·나이·기록 확인, 처음부터 다시 키우기. |
| 가게 | 카스테라·라멘·케이크·약·인형 구입. |

- **시간**: 실시간 4분 = 게임 1일. 앱을 꺼둔 동안에도 최대 3시간치까지 배가 고파집니다.
- **성장**: 알 → (탭 3번) 아기 → 1일차 어린이 → 3일차 어른.
- **분기**: 어린이가 될 때 토벌을 더 많이 했으면 우사기, 놀아준 쪽이 많으면 하치와레, 비슷하면 치이카와가 됩니다.
- **칭호**: 어른이 될 때 돌봄 실수 횟수에 따라 늠름한 / 평범한 / 시무룩한 이 붙습니다.
- 진행 상황은 브라우저 `localStorage`에 저장됩니다(기기·브라우저마다 따로 저장).

## 만든 방식

- 의존성 0. HTML/CSS/바닐라 JS 한 파일, 캐릭터는 전부 인라인 SVG로 직접 그렸습니다.
- 효과음은 Web Audio API 사각파 비프음(우측 상단 ♪ 로 끄기).
- 나가노 작가의 《치이카와》에서 영감을 받은 비상업 팬 게임입니다. 원작 이미지·에셋은 일절 사용하지 않았고,
  캐릭터 그림은 이 저장소를 위해 새로 그린 오리지널 도형입니다.
