# 겨울 소원마을 (산타마을 · 해맞이마을) — 3D 시범판

- 미리보기: https://claude.ai/artifact/W3qSR6uWCQ4SkxhecJEitT (claude.ai 아티팩트, 지금은 대표님만 열림)
- 한 파일(`index.html`)에 두 마을. three.js 0.149(jsDelivr) 3D, 눌러서 걷기, 가까이 가면 행동 버튼. 처음 2D 픽셀판은 `pixel-2d.html`에 보관.
  - 공통: 닉네임·모자 색 고르기, 머리 위 이름표, 표정(이모지 말풍선), 눈덩이 던지기(맞으면 「○○님의 눈덩이에 맞았어요! 되던지기」), 오늘의 선물/복주머니 5개 찾기(날마다 위치 바뀜), 눈멍·바다멍(카메라가 하늘·바다를 봄), 사진 저장
  - 꾸미기: 선물·복주머니를 주우면 아이템이 랜덤으로 나옴(코 5·팔 5·머리 5·목 4·얼굴 4·손 4 = 27개, 흔함 62%·귀함 30%·아주 귀함 8%, 안 가진 것부터). 밤 8시 점등식엔 트리 앞 황금 선물(귀한 것 잘 나옴). 「꾸미기」 옷장에서 갈아입고, 다른 사람에게도 보임(presence `k`). 연속 방문 일수 칩. 사진에 마을 이름·닉네임 도장
  - 장식 눈사람·동글이(이름표 없음)는 마을 꾸밈이고 방문자 수에 안 들어감
  - 산타마을: 눈사람 캐릭터, 소원 트리(장식 = 모두의 소원, 밤 8시~새벽 2시 점등), 통나무집 3채, 가로등, 산타 우체통(편지는 나만 보기), 모닥불, 눈 내림, 크리스마스 D-day
  - 해맞이마을: 털모자 동글이 캐릭터, 바다·해(평소엔 한국 시간대로 하늘색, 전망대에서 해넘이·해돋이 장면), 풍등 광장(풍등 = 모두의 소원, 바다 위로 올라감), 종각(종소리는 같이 있는 사람에게도), 모닥불, 새해 D-day
- 같이 있기: claude.ai `room`(지금 있는 사람 위치·이름·모자·표정, 이벤트 `ball`·`bell`) · 소원 저장: `db` `santa/<사람>` · `sun/<사람>` (한 사람당 마을마다 소원 1개, 다시 쓰면 바뀜) · 편지: `data/users/<사람>/santa-letter`(본인만)
- 글 거르기: 정해진 문구 + 한마디 20자. 욕설·숫자 3개 이상(연락처)·링크는 막음.
- 한계: claude.ai 아티팩트는 로그인한 사람만 소원 저장·같이 있기가 됨. **누구나 들어오는 공개판은 Cloudflare(Workers + Durable Objects)로 옮겨야 함** — 다음 단계.
