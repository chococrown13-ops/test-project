# AI 축구 쇼츠 제작 워크플로우

전체 흐름: **기획 → 대본 → 내레이션(TTS) → AI 영상 생성 → 편집/자막 → 업로드**

## 1. 기획 (5분)

`docs/content-strategy.md`에서 주제를 고르거나, 최근 이슈(이적, 경기 결과)를 활용합니다.

## 2. 대본 작성

```bash
python3 scripts/generate_script.py --topic "주제" --style "정보형|스토리텔링|밈"
```

`templates/script_template.md` 구조(훅-본문-CTA)를 따르며, 씬(Scene) 단위로 나눠
각 씬마다 화면에 뭐가 나와야 하는지 메모해둡니다. AI 영상 생성 도구에 넣을
프롬프트의 기초가 됩니다.

## 3. 내레이션 (TTS)

실사 영상이 아니라 AI 생성 비주얼 + 나레이션 조합이 저작권 이슈 없이 안전합니다.

| 도구 | 특징 | 비용 |
|---|---|---|
| **ElevenLabs** | 가장 자연스러운 한국어/영어 TTS, 감정 톤 조절 | 유료 (무료 티어 있음) |
| **CapCut TTS** | 편집 앱 내장, 간편 | 무료 |
| **Play.ht** | 다양한 보이스, API 지원 | 유료 |
| **OpenAI TTS API** | 저렴하고 API 연동 쉬움 | 유료 (종량제) |

## 4. AI 영상 생성

축구 콘텐츠는 다음 두 방식을 조합하는 것이 실전적입니다.

1. **실제 하이라이트 클립 + 자막/그래픽 오버레이** (저작권 확인 필수 — 뉴스/분석 목적의
   짧은 발췌는 페어유즈 여지가 있지만, 국가/플랫폼 정책을 꼭 확인하세요)
2. **완전 AI 생성 비주얼** (안전하지만 실사 선수 얼굴은 초상권 이슈가 있으니
   실루엣/상징적 이미지/데이터 시각화 위주로)

| 도구 | 용도 |
|---|---|
| **Runway Gen-3/Gen-4** | 텍스트/이미지 → 짧은 영상 클립, 스타디움/역동적 장면 연출 |
| **Pika Labs** | 빠른 반복 생성, 스타일 변환 |
| **Luma Dream Machine** | 자연스러운 카메라 무빙, 스포츠 역동성 표현에 강함 |
| **Kling AI** | 고품질 액션/스포츠 모션 |
| **Midjourney + Runway** | 정적 이미지(Midjourney)를 영상으로 애니메이션화(Runway) |
| **Canva / CapCut 템플릿** | 통계/순위 그래픽은 AI 영상보다 모션 그래픽 템플릿이 더 깔끔함 |

구체적 프롬프트 예시는 `docs/video-prompt-library.md` 참고.

## 5. 편집 & 자막

- **CapCut** (무료, 모바일/PC): 쇼츠 편집 표준. 자동 자막 기능 활용.
- **Adobe Premiere Pro**: 더 정교한 편집이 필요할 때.
- 자막은 필수 (음소거 시청자가 대다수). 폰트는 크고 대비가 강한 색상 사용.
- 인트로 1~2초 안에 훅이 보여야 함 — 텍스트로도 훅 문장을 화면에 노출.

## 6. 썸네일 & 제목

- 세로 9:16 비율, 얼굴/숫자/강렬한 색상 활용.
- 제목에 궁금증 유발 + 숫자 조합 (예: "호날두가 은퇴 후 밝힌 3가지 진실").

## 7. 업로드 체크리스트

- [ ] 자막/캡션 확인 (오탈자 없는지)
- [ ] 저작권 음원 대신 무료 라이선스 BGM 사용 (YouTube Audio Library, Epidemic Sound 등)
- [ ] 초상권/저작권 리스크 있는 실사 클립 사용 시 출처 및 정책 확인
- [ ] 해시태그 3~5개 (#축구 #shorts #축구쇼츠 등 채널 컨셉에 맞게)
- [ ] 각 플랫폼(유튜브/인스타/틱톡)에 맞춰 워터마크 제거 후 개별 업로드

## 8. 성과 분석

- 시청 지속 시간(retention) 그래프에서 이탈 지점을 확인 → 다음 영상의 훅 개선.
- 초반 3초 이탈률이 가장 중요한 지표입니다.
