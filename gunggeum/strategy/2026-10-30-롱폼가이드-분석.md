대표님이 "이 PDF대로 운영하려 한다"며 공유한 자료(게으른 빌더 lazyowen.com, 2026-10-08 공개, 10쪽)를 정리하고 우리 사무실 결정과 비교한 메모입니다. 다음 전략 회의 안건 자료로 씁니다.

## 1. 자료 요약
- 목표: 얼굴 없이 **8분짜리 설명 영상(롱폼)** 을 만들고, 그 영상을 쇼츠 3~5개로 잘라 롱폼으로 사람을 데려온다.
- 분야: 광고 단가가 높은 금융·AI/테크·비즈니스·건강 중 하나. 뉴스·의견이 아닌 **설명 영상**(몇 달 뒤에도 검색됨).
- 도구: 대본은 클로드, 영상은 **힉스필드**(유료 구독 + MCP 커넥터, Editorial Motion Graphics 스킬 = 종이 오려 붙인 화풍 + 자막 + 자료 그래픽).

| 단계 | 내용 | 시간 |
|---|---|---|
| 0 | 단가 높은 분야 고르기, 설명 영상 형식 | — |
| 1 | 이번 달 올라온 얼굴 없는 설명 영상 중 조회수 50만↑ 5~10개 찾기 → 주제 목록(2주치) | 30분 |
| 2 | 그 영상 대본을 "주제 지도"로만 쓰고 최신 조사로 8분 대본 새로 쓰기(문장 베끼기 금지). 사람이 전부 읽고 숫자 확인 | 20분 |
| 3 | 힉스필드 커넥터 연결(claude.ai 설정 → 커넥터 → `https://mcp.higgsfield.ai/mcp`) 또는 CLI | 5분 |
| 4 | Editorial Motion Graphics 로 내레이션·자막·애니메이션·B롤 영상 생성. 같은 화풍·같은 목소리 유지, 크레딧 상한을 대화 첫 줄에 | 1시간 |
| 5 | 대본에서 강한 장면 3~5개 → 9:16 쇼츠, 끝 줄 "전체 설명은 채널에 있습니다" | 30분 |

주간 루틴: 월 리서치 → 화 대본·검수 → 수목 영상 생성 → 금 쇼츠·업로드 예약(주 5~6편). 사람 일은 대본 검수와 완성본 확인.

## 4. 비용 현실
- 힉스필드: 콘텐츠 팩토리 기준 약 1크레딧/초 → 8분 = 약 480크레딧. Plus($49, 1,000크레딧, 약 7만 원)로 **한 달 롱폼 2편** 정도, Starter($15, 200크레딧)로는 8분 1편도 안 됨. 주 5~6편 루틴은 Ultra($129) 이상. Editorial Motion Graphics 스킬의 실제 크레딧은 확인 못 함(위 숫자는 콘텐츠 팩토리 요율로 어림).
- 우리 도구로 만들 경우(추정, 시험 전): 8분 = 이미지 30장 약 $1.4 + 움직이는 장면 2개 약 $1.0 + AI 목소리 → **편당 약 $2.5(3,500원)**. 다만 지금 주간 계획(연재 3·정보 2)이 이미 월 $35를 거의 다 씀 → 롱폼을 넣으려면 쇼츠 편수를 줄여야 함.
