# 건설기술인 역량지수 계산기

자격·경력·학력·교육 점수를 합산해 현재 등급과 다음 등급까지 남은 점수를 계산하는
단일 HTML 페이지입니다. 빌드 도구·서버·외부 스크립트 없이 파일 하나로 동작합니다.

```bash
open icec/index.html    # 브라우저로 바로 열면 됩니다
```

정적 파일이므로 GitHub Pages, Netlify, Vercel 어디에나 그대로 올릴 수 있습니다.
외부 요청은 Google Fonts 하나뿐이고, 입력값은 어디에도 전송되지 않습니다.

## 기능

- 자격·경력·학력·교육 4개 지수 합산 및 항목별 기여도 표시
- **건설사업관리(감리) / 일반 분야 기준선 전환** — 감리는 등급 컷이 5점씩 높습니다
- 다음 등급까지 남은 점수와 진행률
- **등급을 올리는 수단별 예상 상승폭** — 경력 1년·3년, 교육 35시간, 자격 취득, 석사 학위

## 계산 근거

| 항목 | 값 | 상태 |
|---|---|---|
| 역량지수 구성 | 자격 40 + 경력 40 + 학력 20 + 교육 3 | 확인됨 |
| 경력지수 | `(log N / log 40) × 100 × 0.4`, N = 인정 경력 연수 | 확인됨 |
| 교육지수 | 35시간당 1점, 최대 3점, 이수 후 3년 유효 | 확인됨 |
| 등급 기준선 (일반) | 초급 35 / 중급 55 / 고급 65 / 특급 75 | 확인됨 |
| 등급 기준선 (건설사업관리) | 초급 40 / 중급 60 / 고급 70 / 특급 80 | 확인됨 |
| 자격 배점표 | 기술사·건축사 40 / 기사·기능장 30 / 산업기사 20 / 기능사 15 | **검증 필요** |
| 학력 배점표 | 박사 20 / 석사 18 / 학사 16 / 전문학사 14·12 / 고졸 10 | **검증 필요** |

### 공개 전 반드시 할 것

자격·학력 배점표는 공개 자료를 근거로 넣은 값이라 원문 대조가 되지 않았습니다.
개인의 등급·연봉과 직결되는 수치이므로 **건설기술 진흥법 시행규칙 별표 3 원문과
대조해 확정한 뒤** 외부에 공개하세요.

해당 값은 `index.html` 안 `<script>` 최상단 주석 아래 `CUT` 상수와 `#qual`·`#edu`
`<option value="...">` 에 모여 있습니다. 미검증 상태를 알리는 경고 박스가 화면에
표시되므로, 검증을 마치기 전까지 지우지 마세요.

아직 반영하지 않은 것: 학과 관련성(관련/비관련)에 따른 학력 배점 차등,
직무분야·전문분야별 경력 보정계수.
