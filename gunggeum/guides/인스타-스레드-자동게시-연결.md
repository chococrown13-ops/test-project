# 인스타그램·스레드 자동 게시 연결 안내 (대표님용)

목표: 결재함에서 **승인한 카드뉴스·릴스·스레드 글만** 사무실이 대신 올리고, 매주 성과 숫자(조회·저장·공유)도 사무실이 직접 가져오게 합니다.
처음 한 번만 하시면 되고, 30~40분 정도 걸려요. 메뉴 이름은 Meta 화면 개편에 따라 조금 다를 수 있어요.

> 비밀번호·토큰(접속 키)은 **채팅에 붙여 넣지 마세요.** 4단계의 "작업 환경 설정"에만 넣습니다.

---

## 1단계. 인스타그램을 크리에이터 계정으로 바꾸기 (무료, 3분)
1. 인스타그램 앱 → 프로필 → 오른쪽 위 ☰ → **계정 유형 및 도구**(또는 "프로페셔널 계정으로 전환")
2. **크리에이터** 선택 → 카테고리는 "교육" 또는 "디지털 크리에이터"
- 개인 계정은 자동 게시가 안 돼요(Meta 규칙). 크리에이터 계정은 무료이고, 성과 숫자(인사이트)도 볼 수 있어요.

## 2단계. Meta 개발자 앱 만들기 (10분)
1. https://developers.facebook.com 에 페이스북 계정으로 로그인 → 개발자 등록(이름·이메일 확인)
2. **내 앱 → 앱 만들기** → 이름 `도시의 나이테 게시`
3. 사용 사례(Use case)에서 두 가지를 고릅니다
   - **Instagram에서 메시지와 콘텐츠 관리** (Instagram API, Instagram 로그인 방식)
   - **Threads API 액세스**
4. 앱은 "개발 모드" 그대로 두세요. 본인 계정에만 쓰면 Meta 심사가 필요 없어요.

## 3단계. 접속 키(토큰) 두 개 만들기 (15분)

### 인스타그램 키
1. 앱 대시보드 → Instagram 사용 사례 → **Instagram 로그인 기반 API 설정**
2. 권한에 다음이 켜져 있는지 확인: `instagram_business_basic`, `instagram_business_content_publish`, `instagram_business_manage_insights`, `instagram_business_manage_comments`
3. **액세스 토큰 생성 → 계정 추가** → 도시의 나이테 인스타 계정으로 로그인·허락
   - 테스터 초대가 뜨면: 인스타그램 앱 → 설정 → **앱 및 웹사이트 → 테스터 초대** → 수락
4. **토큰 생성**을 누르면 긴 글자(60일짜리 키)가 나와요 → 4단계에서 붙여 넣을 거라 잠시 복사만 해 두세요

### 스레드 키
1. 앱 대시보드 → Threads 사용 사례 → 권한에 `threads_basic`, `threads_content_publish`, `threads_manage_insights`, `threads_manage_replies` 확인
2. **앱 역할 → 역할 → Threads 테스터 추가** → 도시의 나이테 스레드 계정
3. 스레드 앱 → 설정 → 계정 → **웹사이트 권한 → 초대** → 수락
4. Threads 설정 화면의 **사용자 토큰 생성기**에서 계정 옆 **토큰 생성** → 키 복사

## 4단계. 키를 작업 환경에 넣기 (5분)
1. 이 대화 화면 위쪽 제목줄의 **클라우드 환경 메뉴 → 편집(Edit)**
2. **Network secrets**(앱에 따라 "API credentials") 칸이 있으면 거기에, 없으면 **환경 변수**로 두 줄을 넣어요

   | 이름 | 값 |
   |---|---|
   | `INSTAGRAM_ACCESS_TOKEN` | 3단계 인스타그램 키 |
   | `THREADS_ACCESS_TOKEN` | 3단계 스레드 키 |

3. 같은 화면의 **네트워크 허용 도메인(Allowed domains)** 에 추가: `graph.instagram.com`, `graph.threads.net`, `graph.facebook.com`, `rupload.facebook.com`
4. 저장. **새 대화(세션)부터** 적용돼요.

## 5단계. 사진·영상을 올릴 "공개 주소" 정하기 (대표님 결정)
Meta는 사진·영상을 **인터넷에서 누구나 열 수 있는 주소**로만 받아요(파일을 직접 받지 않음). 사무실 자료실은 비공개라 그대로는 못 써요.
- **추천: 공개 GitHub 저장소 하나** (`otter-media` 같은 이름, 0원) — 게시 직전에 그 편의 파일만 올리고, 게시가 끝나면 지워요. 어차피 곧 공개될 파일만 올라가요.
- 대안: Cloudflare R2 같은 파일 보관 서비스(가입·카드 등록 필요).
- 대표님이 "공개 저장소 만들어도 돼"라고 하시면 제가 만들고 연결할게요.

## 끝나면
- 저에게 "연결했어"라고만 말씀해 주세요. 새 세션에서 **글을 올리지 않고** 계정 정보만 읽어서 연결을 확인해요.
- 그다음 게시 도구를 만들어 결재 승인된 것만 예약 게시하게 해요. 승인 없이 올리는 일은 없어요.
- 키는 **60일마다** 다시 만들어야 해요(Meta 규칙). 만료 1주 전에 제가 알려 드릴게요.

## 하지 않는 것
- 유튜브·틱톡 자동 업로드: 플랫폼 심사 전에는 올린 영상이 비공개로 잠겨서, 당분간 대표님이 직접 올려요.
- 네이버 블로그: 공식 글쓰기 API가 확인되지 않아 대표님이 붙여 넣어요.
