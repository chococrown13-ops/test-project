# 대본실 — 대본 도우미 (2026-11-11 대표 요청)

재미는 코드가 아니라 **구성과 개그**에서 나와요. 이 도구는 빠진 것을 찾아 주고, 영상으로 넘기는 일을 줄여 줘요.

## 쓰는 순서 (단계 방식, DeepMind Dramatron 논문의 순서를 참고)
1. **한 줄 줄거리**: "누가 · 무엇을 원하는데 · 무엇이 막는다" 한 문장. 첫 15초 사건을 같이 정해요.
2. **캐릭터**: 시리즈 설정집(예: `channels/story/fridge/bible.md`)의 말버릇·반복 개그를 그대로 써요. 새 캐릭터는 한 편에 한 명까지.
3. **장면 순서(비트)**: 0:00 사건 → 0:30 규칙·목표 → 1:00~ 시도(정보는 무기·증거·단서로) → 2:30쯤 뒤집기 → 결정·감정 → 다음 편으로 잇는 끝 장면 → 댓글 질문.
4. **대사**: 한 줄 38자 이하, 한 장면 25초 안에 움직임·효과음·카드 하나 이상.
5. **점검**: `python3 channels/story/tools/script_helper.py check <대본.md>` → ⚠️ 를 고쳐서 다시.
6. **변환**: `python3 channels/story/tools/script_helper.py build <대본.md> <편 폴더>` → `tts.py <편>` → 장면(index.html이 `l.acts`·`TL.cards`를 읽음) → capture → mix → mp4.

## 대본 쓰는 법 (.md)
- 머리말(--- 사이): `title` · `start` · `gap` · `tail` · `hook` · `cast: 이름 = 목소리 빠르기 [음높이] [muffle]` · `chorus` · `catch`(반복 개그)
- `### 0:35 장면 이름` · `**이름**: (지문) 대사 [효과음] {mood:… gesture:… jump pause:… act:… who:…}`
- `(지문)` 줄 = 화면 움직임(몸개그로 셈). `{act:hand who:우유 mode:grab}` 처럼 쓰면 장면 코드가 그대로 받아요(`at`은 대사 시작 기준 초).
- `[효과음]`: 문 열리는 소리·쿵·땅·탁·뽀글·쏙·찍·데구르르·휙·두둥·반짝·딩동
- `> 카드 제목: 줄1 · 줄2 {card:3}` = 정보 카드(다음 대사부터 3줄 동안)
- 정보가 들어가는 대본은 공식 출처로 확인한 것만 쓰고, 출처를 `publish.md`에 남겨요. 날짜 지난 음식을 먹어도 된다는 말은 쓰지 않아요.

## 점검 기준
| 항목 | 기준 |
|---|---|
| 첫 사건 | `hook`초(기본 15) 안에 움직임·효과음 |
| 심심한 구간 | 25초 넘게 움직임·효과음·카드·큰 몸짓이 없으면 ⚠️ |
| 긴 대사 | 38자 넘으면 나누기(자막 두 줄) |
| 몸개그 | 분당 3개 이상 |
| 반복 개그 | `catch` 마다 2번 이상 |
| 캐릭터 비중 | 주인공이 10% 아래면 대사를 늘려요 |
| 길이 | 목표(시리즈 설정) ±20초. 어림은 1화 실제 목소리 77줄로 맞춘 식(평균 오차 0.5초/줄) |

## 남기는 것
- 대본 `.md` · `check.md`(점검표) · `script.json` 은 커밋, 목소리(`voice/`)·mp4 는 커밋 안 함.
