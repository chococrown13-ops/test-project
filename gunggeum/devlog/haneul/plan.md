# 도시의 나이테 · 원래 ○○이었다 #3 「하늘공원은 원래 쓰레기 산이었다」 — 기획안 (기준일 2026-11-01)

한 줄: 억새가 흔들리는 하늘공원은 15년 동안 서울의 쓰레기가 쌓인 산이었다. 흙을 덮고 가스를 뽑아낸 끝에 2002년 월드컵공원이 됐다. (건강·의료 주제 아님, 차분한 말투)

## 사실과 근거
| 화면 | 확인 | 근거 |
|---|---|---|
| 난지도는 한강 가의 섬이었다(이름은 난초·지초 뜻) | ⚠️ 뜻풀이는 블로그·백과 수준 → **"한강 가의 섬 난지도"까지만 쓰고 이름 뜻은 뺌** | 서울시 미디어허브, 백과 |
| 둑을 쌓아 육지와 이어졌다(1977 시작 설) | ⚠️ 연도 출처 약함 → **연도 없이** | 위키 미러 |
| 1978~1993 서울시 쓰레기 매립지(15년) | ✅ 일치 | 서울시 미디어허브 「난지도 쓰레기가 우리에게 남긴 것」 |
| 쓰레기 산 두 개(높이 90m대) | ✅ 두 개는 확실, 높이는 자료 엇갈림 → **"산 두 개"만** | 서울시 미디어허브 |
| 안정화 사업: 흙 덮기·침출수·가스 처리 | ✅ 내용 일치, 시작 1996/1998 엇갈림 → **연도 없이** | 서울시 미디어허브 |
| 2002.5 월드컵공원 개장, 산 두 개는 하늘공원·노을공원 | ✅ | 서울시 미디어허브 「쓰레기 매립장의 싱그러운 변신」 |
