# EP05 — 고양이한테 우유 주면 좋다? (멍냥 팩트체크 #2)

상태: 결재 대기 (기획안, 1차 검수는 작성자 자체 점검). 이미지·영상은 결재 후.

## 사실 확인표

| 주장 | 판정 | 대본에 쓸 표현 |
|---|---|---|
| 새끼 때는 젖의 유당을 분해하는 효소(락타아제)가 있고, 젖을 떼고 크면서 줄어든다 | ✅ | 아기 때는 젖을 소화해요 |
| 다 큰 고양이 중 많은 수(Cornell: 약 65%)가 유당을 잘 소화 못 한다 | ⚠️ 표현 주의 | 많은 고양이가 우유를 소화하기 어려워해요 (모든 고양이 아님) |
| 못 소화하면 구토·설사·배앓이가 날 수 있다 | ✅ | 배탈이 날 수 있어요 |
| 고양이는 우유 없이도 영양을 충분히 먹는다 (완전 사료가 기본) | ✅ | 우유는 꼭 필요하지 않아요 |
| 유당을 뺀 고양이 전용 우유가 따로 있다 | ✅ | 고양이 전용 우유는 따로 있어요 (간식으로 조금) |
| "모든 성묘가 우유를 먹으면 아프다" | ❌ 과장 | 쓰지 않음 |
| 우유가 고양이에게 좋다/뼈가 튼튼해진다 | ❌ 근거 없음 | 쓰지 않음 |
| 소량(작은 숟가락)을 가끔은 해가 없을 수 있다 | ⚠️ 확인 부족(블로그 수준) | 쓰지 않음 |
