## 0. 사실 확인 (리서치팀)

| 주장 | 판정 | 대본에 쓰는 표현 |
|---|---|---|
| "× 7"은 정확한 근거 없는 어림셈 | ✅ | "× 7은 정확한 계산이 아니라 어림셈이래요" |
| × 7의 기원(1950년대 수명 비교 등) | ⚠️ 확인 부족 | 쓰지 않음 |
| 2020 UC San Diego(Wang 등, *Cell Systems*): 래브라도 104마리·사람 320명 DNA 메틸화 비교 | ✅ | "래브라도 104마리와 사람 320명의 DNA 변화를 비교했대요" |
| 공식 16 × ln(개 나이) + 31 | ✅ | 화면 그대로, 음성 "로그를 쓰는 공식" |
| 1살 ≈ 사람 30살 | ⚠️ 표현 주의 | "30살 안팎". 4살·14살 환산 숫자 금지(발표 자료와 공식이 어긋남) |
| 어릴 땐 빨리, 나이 들수록 천천히 | ✅ | "어릴 땐 훨씬 빨리, 나이 들수록 느려져요" |
| 생후 8주 ≈ 사람 9개월 | ✅ | (분량 때문에 뺌) |
| 연구는 래브라도 한 품종만 | ✅ | "다른 품종도 똑같을지는 이 연구만으론 알 수 없어요" |
| 공식에 크기 보정 없음 | ⚠️ 확인 부족 | 쓰지 않음 |
| 큰 개일수록 빨리 늙는 경향 | ✅ | "큰 개일수록 더 빨리 늙는 경향이 있대요" (숫자 없이) |
| AAHA 2019: 시니어 = 예상 수명의 마지막 25% | ✅ | 설명란 보너스 (크기별 나이표 금지) |
| AAHA: 예상 수명은 품종·크기마다 달라서 단계별 나이를 일괄로 정하지 않음 | ✅ (2차 검수팀 확인, AAHA 2019 지침) | "크기·품종마다 달라요" — 몇 살부터 시니어라는 숫자는 쓰지 않음 |
