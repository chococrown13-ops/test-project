# Football Agent

축구 에이전트 시뮬레이션입니다. 감독이 아니라 **선수 대리인**으로 플레이합니다.
선수를 발굴해 대리인 계약을 따내고, 구단과 이적을 협상하고, 의뢰인의 불만을
수습하면서 수수료로 먹고삽니다.

React + TypeScript + Vite로 만들었고 서버 없이 브라우저에서 전부 돌아갑니다.
모바일 세로 화면(390×844) 기준입니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 로 정적 빌드
npm run preview  # 빌드 결과 확인
```

`vite.config.ts`에 `host: true`가 설정되어 있어 `npm run dev`가 LAN 주소도 함께
출력합니다. PC와 폰이 같은 Wi-Fi에 있으면 그 주소로 접속할 수 있고, iOS Safari에서
"홈 화면에 추가"를 하면 주소창 없이 전체화면으로 실행됩니다.

`main`에 푸시되면 `.github/workflows/deploy.yml`이 GitHub Pages로 배포합니다.
최초 1회만 **Settings → Pages → Source 를 "GitHub Actions"로** 바꿔 주면 됩니다.

## 게임 내용

### 리그 선택과 본거지

새 게임을 시작할 때 **24개국 중 원하는 나라만 골라** 켤 수 있습니다. 켠 나라의
1부 리그는 전부 동시에 진행되고, 끈 나라의 구단과 선수는 세계에서 아예 빠집니다.

그중 하나를 **본거지**로 고릅니다. 본거지만 **4부 리그까지 열리고 승격·강등이
돌아갑니다**. 다른 나라는 1부만 있습니다.

| 대륙 | 국가 |
| --- | --- |
| 유럽 (14) | 잉글랜드, 스페인, 이탈리아, 독일, 프랑스, 포르투갈, 네덜란드, 튀르키예, 벨기에, 우크라이나, 그리스, 덴마크, 스코틀랜드, 오스트리아 |
| 남미 (3) | 브라질, 아르헨티나, 콜롬비아 |
| 아시아 (3) | 사우디아라비아, 일본, 대한민국 |
| 북중미 (2) | 미국, 멕시코 |
| 아프리카 (2) | 모로코, 이집트 |

기본값은 5개 대륙이 모두 채워지는 16개국이고, 전체를 켜면 구단 416개 / 선수 약
1만 명 규모가 됩니다.

**구단은 실제 구단의 이름과 색상을 씁니다.** 엠블럼은 쓰지 않고, 리그 명칭은
`잉글랜드 1부` 같은 중립적인 표기입니다. **선수는 전부 가상**이며 소속 리그의
수준에 맞는 국적 분포로 생성됩니다. 시작 화면에서 가상 구단명으로 돌릴 수도
있습니다 — 그러면 도시 이름을 조합해 실존하는 것과 무관한 세계가 만들어집니다.

각 리그의 구단은 대체로 위상이 높은 순으로 나열해 두었고, **그 순서가 곧
체급**입니다. 여기에 세이브마다 약간의 흔들림이 붙어 매번 같은 팀이 같은 순위로
시작하지는 않습니다.

하부 리그도 목록을 신뢰할 수 있는 나라·부는 실제 구단을 씁니다. 총 **54개
리그 938개 구단**입니다.

| 부 | 실제 구단이 있는 나라 |
| --- | --- |
| 1부 | 24개국 전부 |
| 2부 | 16개국 |
| 3부 | 잉글랜드, 스코틀랜드, 독일, 이탈리아, 스페인, 프랑스, 네덜란드, 포르투갈, 일본, 한국, 브라질 |
| 4부 | 잉글랜드, 스코틀랜드, 독일 |

이탈리아 Serie C(3개 조)나 독일 Regionalliga(5개 조)처럼 **지역별로 쪼개진 부는
각 지역에서 이름 있는 구단을 추려 하나의 전국 표로 합쳤습니다.** 실제 대회 구조와
다르지만, 한 개의 승강 사다리로 이어 붙이려면 어차피 어딘가에서 단순화를 해야
하고, 그럴 바에는 실존 구단을 쓰는 편이 지어낸 이름보다 낫습니다. 목록이 없는
나라·부는 가상 구단으로 채워집니다.

시작 화면이 고른 본거지의 부별로 **실제 구단인지, 지역 리그를 합친 것인지,
가상인지**를 미리 알려 줍니다.

부가 내려갈 때마다 리그 수준이 한 단계씩 뚝 떨어지고, 선수 능력치·주급·구단
재정이 그에 맞춰 함께 내려갑니다. 잉글랜드를 본거지로 잡으면 1부 평균 CA 136에
주급 93k, 4부는 평균 CA 58에 주급 1k 수준입니다.

### 선수 능력치

풋볼 매니저식으로 **1-20 척도 47개 능력치**를 네 그룹으로 나눠 씁니다.

- **기술** (14) — 코너킥, 크로스, 드리블, 마무리, 퍼스트 터치, 프리킥, 헤딩,
  중거리 슛, 롱 스로인, 대인 방어, 패스, 페널티킥, 태클, 테크닉
- **골키핑** (11) — 공중볼 장악, 지역 장악, 의사소통, 돌발성, 핸들링, 킥,
  일대일 방어, 반사신경, 뛰쳐나가기, 펀칭 성향, 던지기
- **정신** (14) — 적극성, 예측력, 대담성, 침착성, 집중력, 판단력, 결단력,
  창조성, 리더십, 오프 더 볼, 위치 선정, 팀워크, 시야, 활동량
- **신체** (8) — 가속도, 민첩성, 균형 감각, 점프, 타고난 체력, 스피드, 지구력, 몸싸움

필드 플레이어는 기술을, 골키퍼는 골키핑을 보고 정신·신체는 공통입니다. 여기에
**주발**(왼발·오른발을 따로 1-20으로 매기고 둘 다 높으면 양발잡이), 키·몸무게,
**포지션별 숙련도**(자연스러움 / 능숙함 / 무난함 / 미숙함 / 어색함), 성격
(프로 정신, 야심가, 충성심, 돈에 민감… 10종), 그리고 숨겨진 현재 능력 / 잠재
능력이 붙습니다.

능력치는 처음부터 다 보이지 않습니다. **파악도가 낮으면 범위로만** 표시되고
(`9–17`), 집중 관찰로 파악도를 올리면 정확한 값이 드러납니다.

### 대회

- **국가별 1부 리그** — 홈·원정 더블 라운드로빈. 순위표, 득점·도움 순위.
- **대륙 클럽 대항전 5개** — 유러피언 클럽컵, 코파 수다메리카나컵, 아시안 클럽컵,
  북중미 클럽컵, 아프리칸 클럽컵. 리그 상위 팀이 나가고 녹아웃으로 치릅니다.
- **클럽 월드컵** — 대륙 챔피언들이 시즌 막바지에 만납니다.

### 개인 수상

43주차 시상식에서 한꺼번에 발표됩니다.

- **리그별** — 득점왕, 도움왕, 올해의 선수, 영플레이어(21세 이하), 골든글러브
- **대륙별** — 대륙 올해의 선수, 대륙컵 득점왕
- **세계** — 세계 올해의 선수, 세계 영플레이어, 세계 득점왕

점수는 대회 수준으로 가중되므로 약한 리그에서 40골을 넣어도 강한 리그의 25골을
이기기 어렵습니다. 수상 이력은 선수 개인 프로필에 평생 남습니다.

### 에이전트 플레이

- **스카우팅과 사정권** — 포지션·나이·리그·대리인 유무로 조건을 걸고 포인트를 써서
  훑습니다. **평판이 낮으면 상위 리그는 아예 명단에 뜨지 않습니다** — 무명
  에이전트의 전화를 1부 구단이 받아 주지 않기 때문입니다. 시작 평판(12)으로는
  본거지의 3·4부만 보이고, 거래를 성사시켜 이름값이 쌓이면 위쪽 리그가 차례로
  열립니다. 스카우트 화면이 다음에 열릴 리그와 필요한 평판을 항상 보여 줍니다.
- **영입 제안** — 수수료율을 직접 정해 제안합니다. 낮게 부를수록 잘 넘어오지만
  앞으로 들어올 돈이 줄어듭니다.
- **이적 협상** — ① 이적료(두 구단) → ② 선수 조건(주급·기간·바이아웃) →
  ③ 내 수수료. 각 단계마다 상대에게 한계선과 인내심이 있고, **퇴짜를 맞으면 상대가
  자기 선을 흘립니다.** 찔러서 알아낸 뒤 그 안에서 최선을 뽑아내는 구조입니다.
  구단 목록에는 그 구단이 이 선수를 실제로 원하는지가 먼저 표시됩니다.
- **의뢰인 관리** — 출전 시간, 주급, 이적 요구, 징계, 개인사. 마감 안에 처리하지
  않으면 신뢰가 떨어지고, 바닥나면 다른 에이전트에게 갑니다.
- **평판과 라이선스** — 큰 거래를 성사시킬수록 평판이 오르고, 등급이 오르면
  의뢰인 정원과 동시 협상 수가 늘어납니다.
- **이적시장** — 여름(1~6주)과 겨울(23~25주)에만 열립니다. 재계약은 언제든 가능합니다.

자동 저장됩니다. 세이브는 gzip으로 압축해 `localStorage`에 넣습니다.

## 구조

```
src/
  data/
    countries.ts     24개국 · 5개 대륙 정의, 부별 체급·해금 조건
    clubs.ts         54개 리그 938개 구단 (1~4부, 이름·약칭·색상, 위상 순)
    names.ts         지역별 선수 이름 풀, 가상 구단명 패턴
  game/              엔진 (React 의존성 없음, 순수 TypeScript)
    attributes.ts      FM식 능력치 47개, 포지션, 주발
    rng.ts             시드 기반 난수
    player.ts          선수 생성, 성격, 시장 가치, 주급
    ratings.ts         능력치 → 팀 전력 압축
    match.ts           경기 해석, 득점·도움·평점 배분
    world.ts           세계 생성, 일정, 대륙 대항전 대진
    season.ts          주간 진행, 시즌 마감, 성장·노화·은퇴·유스
    market.ts          AI 이적 시장, 재계약, 자유계약
    awards.ts          개인 수상 산정
    agent.ts           자금, 평판, 라이선스, 구단 관계
    scouting.ts        발굴과 파악도
    clients.ts         대리인 계약, 신뢰, 요구 사항
    negotiation.ts     3단계 협상
    engine.ts          한 주 진행 오케스트레이션
    save.ts            압축 세이브
  store/useGame.ts   zustand 스토어
  ui/                화면과 컴포넌트
tools/
  simulate.ts        헤드리스 밸런스 검증
  playthrough.ts     에이전트 루프 전체 시연
```

엔진은 React를 참조하지 않아 Node에서 그대로 돌릴 수 있습니다.

## 밸런스

```bash
npm run sim -- 12 24    # 12시즌 × 24개국
npm run play            # 에이전트 루프 한 바퀴
npm run clubcheck       # 구단 데이터 정합성 (부별 인원 수·부 간 중복·약칭·색상)
npm run tiercheck       # 부별 체급, 스카우팅 해금, 승격·강등
```

24개국 12시즌(약 8만 경기) 기준입니다.

| 지표 | 결과 | 실제 리그 참고값 |
| --- | --- | --- |
| 경기당 득점 | 2.54 | ~2.7 |
| 홈승 / 무 / 원정승 | 42% / 26% / 32% | ~44% / 25% / 31% |

`npm run sim`은 매 시즌 불변식도 검사합니다 — 스쿼드 인원, 구단당 골키퍼 최소 2명,
선수가 두 구단에 동시에 존재하지 않는지, 은퇴 선수가 명단에 남아 있지 않은지,
세계 평균 연령이 무너지지 않는지.

긴 시뮬레이션에서만 드러난 문제 셋을 잡아 두었습니다. 계약이 만료돼도 아무도
재계약을 하지 않아 여덟 시즌이면 세계가 통째로 자유계약 선수가 되던 것, 유망주가
출전 시간만으로 성장해 잠재력의 절반도 못 채우던 것, 아카데미가 스쿼드에 빈자리가
있을 때만 선수를 배출해 재능 공급이 마르던 것. 지금은 열다섯 시즌을 돌려도 세계
최고 수준(CA 170대)과 평균 연령(24세 안팎)이 자리를 지킵니다.

## 성능과 용량

24개국을 전부 켠 세계는 구단 416개, 선수 약 10,500명, 시즌당 약 7,000경기입니다.

- 세계 생성 ~0.3초, 한 주 진행 ~40ms, 시즌 롤오버 ~2초
- 세이브는 선수 레코드를 키 없는 배열로 눕히고 능력치 47개를 한 글자씩 문자열로
  눌러 담은 뒤 gzip으로 압축합니다. 3.9MB → 약 1.0MB.

휴대폰에서는 16개국 안팎을 권합니다. 시작 화면이 선택한 규모를 미리 알려 줍니다.

## 현재 없는 것

- 본거지가 아닌 나라의 하부 리그 (그 나라들은 1부만 돌아갑니다)
- 리그별 고유 형식 — 미국·멕시코의 컨퍼런스와 플레이오프, 남미의 아페르투라 ·
  클라우수라 분리 같은 것은 반영하지 않고 전부 홈·원정 더블 라운드로빈입니다.
- 국가대표팀과 대륙 국가대항전
- 임대 이적, 공동 소유
- 경기 중계 화면 (결과만 산출합니다)
- 다른 에이전트와의 직접 경쟁 (의뢰인을 뺏고 뺏기는 정도만 있습니다)
