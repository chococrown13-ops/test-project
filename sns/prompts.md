# Claude 프롬프트 템플릿

`{중괄호}` 부분만 바꿔서 Claude에 붙여넣으세요.
사실 확인이 필요한 단계에서는 Claude의 **웹 검색 기능을 켜세요.**

---

## 0. 계정 설정 (처음 한 번)

Claude의 **프로젝트** 기능에 아래 내용을 "프로젝트 지침"으로 넣어두면, 매번 설명하지 않아도 같은 톤으로 작성합니다.

```
너는 SNS 호기심 계정 「{계정 이름}」의 작가다.

[계정 정체성]
- 주제: 동물의 신기한 사실, 세계 여러 나라의 문화, 세계 건축을 미니어처로 표현한 콘셉트 아트
- 타깃: 10~30대, 짧은 영상으로 새로운 사실을 알고 싶은 사람
- 톤: 친근한 반말은 쓰지 않고 "~거든요", "~래요" 같은 가벼운 존댓말. 과장 없이 놀라움을 전달.

[원칙]
- 확인된 사실만 쓴다. 확신이 없으면 "확인 필요"라고 표시하고 대본에 넣지 않는다.
- 나라·민족에 대해 일반화하지 않는다. "○○ 사람들은 다~" 대신 "○○의 일부 지역에서는~".
- 모든 결과물 끝에 사용한 출처를 목록으로 붙인다.
- 우리는 미니어처를 직접 만들지 않는다. "만들었다"는 표현을 쓰지 않고 "AI로 그려봤다/상상해봤다"로 쓴다.
```

## 1. 채널 이름

```
위 계정 정체성에 맞는 채널 이름 후보 15개를 제안해줘.
조건: 한글 2~6글자 또는 짧은 영어, 발음하기 쉬움, 동물·문화 어느 쪽에도 어울림.
각 이름마다 인스타그램 핸들(@) 후보 2개도 함께. 표로 정리.
```

## 2. 주제 발굴

```
「{코너 이름, 예: 동물 반전 상식}」 코너용 주제 20개를 제안해줘.
조건:
- 첫 문장만 들어도 "진짜?" 하고 멈출 만한 사실
- 과학적/역사적으로 확인 가능한 사실만 (근거 출처 한 줄씩)
- 이미 너무 유명한 것(예: 문어 심장 3개)은 "유명도: 높음" 표시
표 형식: 번호 | 주제 | 한 줄 훅 | 근거 출처 | 유명도(높음/중간/낮음)
```

## 3. 사실 확인 (대본 쓰기 전에 꼭)

```
다음 주제로 영상을 만들려고 해: {주제}
웹 검색으로 아래를 확인해줘.
1. 이 사실이 맞는지, 과장되거나 틀린 부분이 있는지
2. 신뢰할 만한 출처 2개 이상 (학술 자료, 공공기관, 주요 언론, 박물관 등)
3. 흔히 퍼져 있는 잘못된 버전이 있다면 무엇인지
4. 영상에 넣어도 되는 문장 / 빼야 하는 문장 구분
```

## 4. 쇼츠·릴스 대본 (40초)

```
주제: {주제}
확인된 사실: {3단계 결과 붙여넣기}

40초 세로 영상 대본을 써줘.
구성:
- [0~2초] 훅: 질문이나 반전 한 문장 (15자 이내)
- [2~30초] 본문: 사실 3개, 각각 한두 문장. 뒤로 갈수록 더 놀라운 순서로
- [30~40초] 마무리: 댓글을 부르는 질문 또는 다음 편 예고
조건: 전체 350자 내외(한국어 TTS 기준 약 40초), 문장은 짧게, 숫자는 구체적으로.
출력 형식: 시간 | 내레이션 | 화면 자막(내레이션보다 짧게) | 화면 설명
```

## 5. 장면별 이미지/영상 프롬프트

```
위 대본의 각 장면에 맞는 이미지 생성 프롬프트를 영어로 써줘.
공통 스타일: {예: "soft 3D render, warm natural lighting, vertical 9:16, no text"}
조건:
- 장면마다 하나씩, 번호를 대본과 맞출 것
- 화면 속에 글자가 들어가지 않게 (자막은 편집에서 넣음)
- 실존 인물, 브랜드 로고, 구단 엠블럼 금지
- 영상 생성 도구용으로 카메라 움직임도 한 줄 추가 (예: slow push-in)
```

## 6. 미니어처 콘셉트 아트

```
「미니어처로 보는 세계 전통 가옥」 시리즈 {나라} 편.
1. 이 나라 전통 가옥의 특징 3가지 (건축 재료, 형태, 그렇게 지은 이유) — 출처 포함
2. 틸트시프트 미니어처 디오라마 스타일 이미지 프롬프트 3개 (영어)
   - "tilt-shift miniature diorama, handcrafted look, shallow depth of field" 계열
   - 계절이나 시간대만 다르게
3. 캡션: "직접 만든 것이 아니라 AI로 그려본 이미지"임을 자연스럽게 밝힐 것
```

## 7. 카드뉴스 (인스타 캐러셀 7장)

```
주제: {주제}
인스타그램 캐러셀 7장 문구를 써줘.
- 1장: 표지. 큰 제목(12자 이내) + 부제
- 2~6장: 장마다 사실 하나. 제목 한 줄 + 본문 2~3줄(60자 이내)
- 7장: 요약 + "저장해두고 친구에게 공유하기" 같은 행동 유도
각 장마다 배경 이미지 프롬프트(영어)도 함께.
```

## 8. 캡션·해시태그 (플랫폼별)

```
다음 영상의 게시 문구를 플랫폼별로 써줘: {대본 요약}
- 유튜브 쇼츠: 제목(40자 이내, 검색될 키워드 포함) + 설명 2줄 + 해시태그 3개
- 인스타그램 릴스: 캡션 3~4줄(첫 줄에 훅) + 해시태그 10개 (큰 태그 3, 중간 4, 작은 3)
- 틱톡: 캡션 1~2줄 + 해시태그 4개
- 공통: 마지막 줄에 "이 콘텐츠는 AI로 제작되었습니다" 표기
```

## 9. 축구 계정: 경기 한 줄 평 / 상식

```
{경기: 팀A vs 팀B, 결과, 주요 장면 메모}
스레드용 글 3가지 버전을 써줘.
- 버전1: 한 줄 평 (60자 이내, 위트 있게)
- 버전2: 관전 포인트 3개 정리
- 버전3: 다음 경기 예측 + 팔로워에게 질문
조건: 확인되지 않은 이적설·부상 정보는 쓰지 않는다. 선수 비하 금지.
```

```
축구 상식 주제: {예: 오프사이드 규칙은 왜 생겼을까}
웹 검색으로 확인한 뒤, 카드뉴스 6장 문구와 전술 도식이 필요하면 SVG 코드로 그려줘.
```

1. 잘된 게시물과 안된 게시물의 차이를 분석해줘 (훅, 주제, 길이, 게시 시간)
2. 다음 주에 유지할 것 / 바꿀 것 3개씩
3. 반응 좋은 주제에서 파생되는 다음 주 주제 7개
