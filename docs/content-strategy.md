# 축구 쇼츠/릴스 콘텐츠 전략

## 1. 채널 컨셉 정하기

한 채널에서 너무 많은 걸 다루면 알고리즘이 시청자를 특정하기 어렵습니다.
아래 4가지 컨셉 중 하나를 메인으로 잡고 시작하는 것을 추천합니다.

| 컨셉 | 설명 | 난이도 |
|---|---|---|
| **기록/통계 비교형** | "메시 vs 호날두 통산 골", "역대 이적료 TOP 10" 같은 데이터 기반 콘텐츠 | ⭐ 쉬움 |
| **전술 분석형** | 특정 팀/감독의 전술, 포메이션, 명장면 분석 | ⭐⭐⭐ 어려움 (축구 지식 필요) |
| **레전드 스토리텔링형** | 선수의 인생 서사, 반전 스토리, 은퇴/부상 극복기 | ⭐⭐ 보통 |
| **밈/하이라이트 재해석형** | 유명 장면을 AI 영상으로 재해석, 유머 코드 | ⭐⭐ 보통 |

## 2. 쇼츠 구조 공식 (15~60초)

```
[0~2초] 훅(Hook)  — 스크롤을 멈추게 하는 한 문장 or 강렬한 비주얼
[2~8초] 문제 제기 — "왜 이게 특별한가?" 궁금증 유발
[8~45초] 본문 — 핵심 정보 3개 이내, 숫자/사실 위주
[45~55초] 반전/결론 — 예상 밖의 인사이트
[55~60초] CTA — 팔로우/댓글 유도 질문
```

## 3. 후킹(Hook) 문장 템플릿

- "OO가 절대 하지 않는 것 한 가지"
- "축구 역사상 가장 이해할 수 없는 기록"
- "만약 OO가 이 팀에 갔다면?"
- "이 골이 왜 역대급인지 90%는 모릅니다"
- "숫자로 보면 완전히 달라지는 이야기"

## 5. 업로드 주기 & 시리즈화

- 주 3~5회 업로드가 알고리즘에 유리합니다.
- "메시 vs 호날두 시리즈", "이주의 골" 처럼 시리즈명을 고정하면
  구독자가 다음 편을 기대하게 됩니다.
- 썸네일/제목에 숫자를 넣으면 클릭률이 올라갑니다 (예: "TOP 5", "3가지 이유").
