# 겨울 소원마을 홍보 쇼츠 #1 (30초)

- 영상: `village_promo.mp4` (1080×1920, 30초, 배경음 코드 생성 — 멜로디도 새로 지음) — 사무실 자료실에 있음, 커밋 안 함
- 만들기: `village`에서 `npx wrangler dev --port 8787` → `node promo/capture.cjs <프레임 폴더>` (가상 시계로 실제 마을 화면을 한 프레임씩) → `python3 promo/audio.py music.wav` → ffmpeg
- 화면 속 눈사람은 "나" 하나와 마을 장식 인형뿐. 방문자를 꾸며 넣지 않음. 시간은 12월 1일 밤 9시 반으로 맞춰 트리 점등 장면을 찍음
- 장면: AI한테 산타마을 만들어 달라고 했더니 → 걸어 다니기 → 소원 트리 장식 → 선물에서 꾸미기 아이템 → 눈덩이 → 해맞이마을 해돋이 → 끝 화면(12월 1일 오픈 · 매일 밤 8시 점등식 · 링크는 프로필에)
