# 냉장고 속 회의 — 시리즈 설정집 (시즌 1, 2026-11-11)

밤마다 사람이 잠들면 냉장고 속 음식들이 회의를 열어요. 웃긴 대화 속에 **진짜 생활 정보**(소비기한·보관법·표시 읽는 법)가 하나씩 들어 있어요.
- 형식: 가로 롱폼(1920×1080), 5~6분에서 시작 → 시청 유지율이 40%를 넘으면 8분으로 늘림. 편마다 세로 쇼츠 1~2개를 잘라 냄. 한 달에 한 번 30분 모음집.
- 제작: 코드 3D(three.js 툰 그림) + Google TTS 목소리(무료 한도 안) + Rhubarb 입 모양 + 코드 배경음 → 0원.
- 규칙: 정보는 공식 기록으로 확인된 것만 넣어요. 확인 안 된 건 농담으로만 쓰고 정보처럼 말하지 않아요. AI 목소리·AI 제작 사실은 설명란에 밝혀요.
