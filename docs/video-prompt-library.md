# AI 영상 생성 프롬프트 라이브러리 (축구)

Runway / Pika / Luma / Kling 등 텍스트→영상(T2V) 도구에 바로 사용할 수 있는
축구 특화 프롬프트 예시입니다. 실제 선수 얼굴 대신 **실루엣, 상징적 앵글,
데이터 시각화**를 활용해 초상권 이슈를 피하는 방식을 기본으로 합니다.

## 사용 팁

- 카메라 무빙 키워드를 넣으면 더 역동적입니다: `slow motion`, `dynamic tracking shot`,
  `low angle`, `drone shot`, `handheld camera shake`
- 조명/분위기: `stadium floodlights`, `golden hour`, `dramatic rim lighting`, `fog and stadium lights`
- 스타일: `cinematic`, `hyper-realistic`, `film grain`, `slow motion 120fps look`

## 프롬프트 예시

### 오프닝 훅 컷 (스타디움 분위기)
```
A packed football stadium at night, dramatic floodlights cutting through fog,
crowd silhouettes roaring, slow motion, cinematic wide shot, film grain,
photorealistic, 9:16 vertical
```

### 골 세리머니 (실루엣)
```
Silhouette of a football player sliding on his knees in celebration,
stadium lights flaring behind him, confetti falling, slow motion,
dramatic backlight, cinematic, 9:16 vertical
```

### 드리블/액션 연출 (얼굴 없이 다리/공 클로즈업)
```
Close-up low angle shot of football boots dribbling a ball on green grass,
motion blur, dynamic tracking camera, stadium light reflections on the pitch,
slow motion, cinematic, 9:16 vertical
```

### 통계/데이터 비교 씬 (그래픽 연출용 배경)
```
Abstract minimalist background with glowing football statistics and numbers
floating in dark space, blue and gold light particles, futuristic data
visualization style, smooth camera drift, 9:16 vertical
```

### 트로피/우승 장면
```
Golden football trophy on a pedestal, spotlight from above, slow rotating
camera, confetti falling in background, cinematic reflections, dramatic,
9:16 vertical
```

### 전술 보드/분석 느낌
```
Top-down view of a football tactics board with glowing tactical lines and
player positions animating, dark background, holographic UI style,
smooth animation, 9:16 vertical
```

### 훈련장/새벽 연습 (스토리텔링용)
```
Lone football player practicing alone on an empty training pitch at dawn,
soft golden light, long shadows, mist on the grass, cinematic slow motion,
emotional tone, 9:16 vertical
```

### 이적/이슈 뉴스 인트로
```
Fast-paced montage style background, newspaper headlines and football club
crests flying past camera, dynamic light streaks, modern broadcast graphics
style, energetic, 9:16 vertical
```

## 저작권/초상권 주의사항

- 실제 선수의 얼굴을 AI로 생성해 실사처럼 보이게 하는 것은 초상권·인격권 분쟁 소지가 있습니다.
  가능하면 실루엣/뒷모습/추상적 표현을 사용하세요.
- 실제 방송사 하이라이트 영상을 그대로 사용하는 것은 저작권 침해가 될 수 있습니다.
  분석/비평 목적의 짧은 발췌 + 자체 해설을 결합하는 방식을 권장하며, 플랫폼별 저작권
  정책(유튜브 Fair Use 가이드 등)을 반드시 확인하세요.
- 클럽 로고/엠블럼도 상표권이 있으므로 상업적 사용 시 유의가 필요합니다.
