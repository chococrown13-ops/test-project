# Gaffer

풋볼 매니저 스타일의 축구 감독 시뮬레이션 웹 게임입니다. PC(가로 1024px 이상)에서는 FM처럼
사이드바 + 대시보드 레이아웃으로, 휴대폰에서는 세로 탭 레이아웃으로 표시됩니다.
React + TypeScript + Vite로 작성했고, 서버 없이 브라우저에서 전부 동작합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 로 정적 빌드
npm run preview  # 빌드 결과물 확인 (http://localhost:4173)
```

- **PC (1024px 이상)** — 왼쪽 사이드바 메뉴, 상단의 `계속 ▶` 버튼(FM의 Continue), 홈 대시보드,
  능력치가 전부 보이는 선수단 표(열 클릭 정렬), 넓은 2D 경기 화면.
- **휴대폰** — 390×844(아이폰 세로) 기준의 하단 탭 레이아웃.

### 휴대폰에서 열기

`vite.config.ts`에 `host: true`가 설정되어 있어 `npm run dev`를 실행하면 LAN 주소도 함께 출력됩니다.
PC와 폰이 같은 Wi-Fi에 있으면 그 `Network` 주소로 접속할 수 있습니다. iOS Safari에서 "홈 화면에
추가"를 하면 주소창 없이 전체화면으로 실행됩니다.

## 배포

`main`에 푸시되면 `.github/workflows/deploy.yml`이 빌드해 GitHub Pages로 배포합니다.
Actions 탭에서 수동 실행(`workflow_dispatch`)도 가능해 머지 전에 미리 확인할 수 있습니다.

최초 1회만 저장소 설정이 필요합니다: **Settings → Pages → Source 를 "GitHub Actions"로 변경.**

백엔드가 없는 정적 사이트라 Netlify, Vercel, S3 등 어디에 올려도 그대로 동작합니다.
`vite.config.ts`의 `base: './'` 덕분에 하위 경로(`/test-project/`)로 서빙해도 문제가 없습니다.

## 과일 톡톡 (`games/merge/`)

같은 저장소에 들어 있는 두 번째 게임으로, 수박게임 스타일의 물리 합치기 퍼즐입니다.
같은 과일끼리 닿으면 한 단계 큰 과일이 되고, 과일이 점선 위로 2.5초 넘게 쌓여 있으면 게임이 끝납니다.

```bash
npm run dev:merge   # http://localhost:5173/games/merge/
```

- **조작** — 휴대폰은 드래그로 위치를 정하고 손을 떼면 떨어집니다. PC는 마우스를 움직이고 클릭,
  또는 ←/→ 이동 후 스페이스.
- **과일 11단계** — 체리 › 딸기 › 포도 › 귤 › 감 › 사과 › 배 › 복숭아 › 파인애플 › 멜론 › 수박.
  떨어뜨릴 수 있는 건 앞의 5개뿐이고 나머지는 합쳐서 만들어야 합니다. 수박 두 개가 합쳐지면
  보너스 100점과 함께 사라집니다.
- **점수** — 만들어진 과일 단계에 따라 1, 3, 6, 10…점. 0.9초 안에 연달아 합치면 콤보 보너스.
- **연출** — 과일 그림은 전부 캔버스로 그려 단계별로 한 번만 스프라이트로 굽습니다(이미지 파일 없음).
  합쳐질 때 파티클·점수 팝업·진동, 큰 과일은 화면 흔들림. 효과음은 Web Audio로 합성합니다.
- **기록** — 최고 점수와 지금까지 만든 가장 큰 과일이 `localStorage`에 남고, 하단 진화표에서
  아직 못 만든 과일은 회색으로 표시됩니다.

물리는 [matter-js](https://brm.io/matter-js/)를 쓰고, 게임 규칙(`game.ts`)은 DOM을 전혀 참조하지 않습니다.
빌드하면 `dist/games/merge/`로 함께 나오므로 GitHub Pages에서는 `…/test-project/games/merge/`로 열립니다.

```
games/merge/
  index.html       페이지와 HUD·오버레이 마크업
  src/fruits.ts    과일 단계 정의와 캔버스 그림
  src/game.ts      matter.js 월드, 합치기·콤보·게임오버 규칙
  src/audio.ts     Web Audio 효과음
  src/main.ts      렌더링, 입력, HUD
```

## 스도쿠 도장 (`games/sudoku/`)

중·상·최상·극상 네 난이도의 스테이지와, 풀이 기법을 배우는 학습 채널이 있는 스도쿠입니다.

```bash
npm run dev:sudoku   # http://localhost:5173/games/sudoku/
```

- **스테이지** — 난이도마다 50개, 번호가 클수록 어렵습니다. 클리어 기록(시간·실수·힌트)과
  진행 중인 판이 저장되고, 홈에서 이어하기로 바로 돌아갑니다.
- **난이도 판정** — 사람처럼 푸는 풀이기(`solver.ts`)가 가장 쉬운 기법부터 적용해 끝까지 풀었을 때
  필요했던 가장 어려운 기법으로 정합니다. 모든 스테이지는 학습 채널에서 가르치는 기법만으로 풀리고,
  답이 하나뿐입니다.

  | 난이도 | 반드시 한 번 이상 필요한 기법 |
  | --- | --- |
  | 중 | 포인팅, 클레이밍, 네이키드/히든 페어 |
  | 상 | 네이키드/히든 트리플, X-윙, XY-윙 |
  | 최상 | 스카이스크래퍼, 투스트링 카이트, 터봇 피시, 소드피시, XYZ-윙, W-윙, 유니크 렉탱글, 쿼드 |
  | 극상 | 젤리피시, X-체인, XY-체인 |

- **학습 채널** — 23가지 기법을 5개 장으로 나눠 설명, 찾는 법, 실제 퍼즐에서 뽑은 예시 보드를 보여 줍니다.
  기법마다 연습 문제 5개가 있고, 지울 수 있는 후보를 직접 탭해서 맞힙니다(같은 기법의 다른 정답도 인정).
- **힌트** — 지금 판면에서 다음에 쓸 기법의 이름과 이유를 보여 주고, 패턴 칸·후보·체인 연결선을
  보드에 표시합니다. `배우기`를 누르면 그 기법의 학습 페이지로 갑니다. 틀린 숫자가 있으면 그것부터 알려 줍니다.
- **조작** — 메모, 자동 메모, 되돌리기, 지우기. PC에서는 숫자키·방향키·`N`(메모)·Ctrl+Z.
- **테마 두 가지** — 홈 화면이나 게임 메뉴에서 고릅니다(처음엔 기기의 다크 모드 설정을 따름).
  - **먹** — 먹빛 바탕, 상아색 명조 숫자(Cormorant Garamond · 나눔명조), 금색 가는 선, 붉은 네모 인장 「解」.
  - **봄** — 점무늬 크림색 종이, 굵은 갈색 테두리와 스티커 그림자, 둥근 숫자(Fredoka · 주아),
    분홍 「참 잘했어요」 도장.
- **도장판과 손맛** — 스테이지 목록은 도장판이라, 한 판을 풀 때마다 도장이 찍힙니다. 클리어하면 보드에
  물결이 지나간 뒤 도장이 내려찍히고, 행·열·박스를 완성할 때도 그 줄에 물결이 지나갑니다.
  바둑돌 놓는 듯한 효과음과 진동(지원 기기)은 메뉴에서 끌 수 있습니다. 아이콘은 모두 직접 그린 선 아이콘입니다.
- 웹폰트는 Google Fonts에서 불러오되 로딩을 막지 않아서, 폰트가 늦거나 막혀도 게임은 바로 시작됩니다.

## 게임 내용

- **16개 구단, 30라운드 더블 라운드로빈.** 모든 구단과 선수는 가상입니다.
- **선수단** — 23명 스쿼드, 선발 11명 / 교체 7명. 선수를 탭해 선택하고 다른 선수를 탭하면 자리가
  바뀝니다. 같은 선수를 다시 탭하면 능력치·컨디션·시즌 기록 상세를 봅니다.
- **전술** — 5가지 포메이션(4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2), 팀 성향·템포·압박·패스 길이.
  각 설정은 경기 엔진의 공격/중원/수비 수치에 실제로 반영됩니다.
- **경기 (3D 중계)** — 모바일 기준으로 만든 3D 경기 화면(three.js). 관중석·광고판·조명탑이 있는
  경기장에서 22명의 3D 선수(무릎·팔꿈치 관절, 등번호, 헤어스타일)가 달리기·킥·골 세리머니 모션으로 움직이고,
  실시간 그림자·필름 톤매핑·잔디 결과 마모까지 표현합니다. 폰이 버거워하면 자동으로 저화질(그림자 단순화)로 내려갑니다.
  카메라는 중계 화면처럼 공을 따라가다가
  찬스·골 장면에서는 가까이 당겨 잡습니다. `🎥 중계` / `🗺 전체` 버튼으로 시점을 바꾸고, `3D` 버튼으로
  가벼운 2D 탑뷰로 전환할 수 있습니다(저사양 폰용, 선택은 기억됨. WebGL이 없으면 자동으로 2D).
  엔진이 만든 찬스·골·선방·빗나감·차단·파울·카드·부상마다 해당 선수가 직접 등장하는 하이라이트를
  재생하며, 하이라이트가 끝나야 시계가 다시 흐르고 스코어와 중계 문구도 장면이 나온 뒤에 공개됩니다.
  일시정지 / 1x / 2x / 4x / 끝까지 건너뛰기, 경기 중 교체(5회)와 전술 변경.
- **이적시장** — 시즌당 두 번(프리시즌 3라운드, 겨울 2라운드) 열립니다. 다른 구단 선수에게
  금액을 제시해 영입하고, 내 선수를 이적 리스트에 올려 제안을 받습니다. 이적료·주급 상한·
  스쿼드 인원(18~28명)·골키퍼 최소 보유가 모두 제약으로 걸립니다. AI 구단끼리도 거래합니다.
- **시즌 진행** — 순위표, 일정, 득점 순위, 이사회 목표와 중간 평가, 시즌 종료 후 선수 성장·노화·
  은퇴와 유스 충원, 순위에 따른 상금.
- **커스터마이즈** — 리그 이름과 16개 구단 전부의 이름·약칭·색상을 직접 바꿀 수 있습니다.
  시작 화면에서 리그명과 내 구단명을, 게임 중에는 구단 탭에서 언제든 편집합니다.
- **자동 저장** — 진행 상황은 `localStorage`에 저장되고 새로고침하면 이어집니다. 업데이트로
  필드가 추가되어도 기존 세이브는 마이그레이션되어 그대로 이어집니다.

## 구조

```
src/
  game/          엔진 (UI 의존성 없음, 순수 TypeScript)
    types.ts         공용 타입
    rng.ts           시드 기반 난수 (mulberry32)
    names.ts         구단·선수 이름 풀
    formations.ts    포메이션 슬롯과 피치 좌표, 포지션 적합도
    generate.ts      선수/스쿼드/리그/일정 생성, 자동 선발
    ratings.ts       능력치 → 팀 전력 환산, 전술 반영
    commentary.ts    중계 문장 템플릿
    matchEngine.ts   분 단위 경기 시뮬레이션
    league.ts        순위표, 최근 폼
    season.ts        회복/사기/성장/시즌 롤오버
    transfer.ts      이적시장 — 창구, 호가, 제안 평가, AI 거래
    save.ts          localStorage 저장·불러오기 (+ 구버전 마이그레이션)
  store/useGame.ts   zustand 스토어 (엔진과 UI 연결)
  ui/                화면과 컴포넌트
    match2d/           경기 연출 (director.ts: 선수·공 움직임과 하이라이트 시나리오) + 2D 렌더링
    match3d/           3D 렌더링 (scene3d.ts, three.js — 경기 화면에 들어갈 때만 불러옴)
    screens/HomeScreen.tsx  PC 대시보드
```

엔진(`src/game/`)은 React를 전혀 참조하지 않아서 Node에서 그대로 돌려 밸런스를 검증할 수 있습니다.

## 밸런스

6시즌 1,440경기를 돌려 맞춘 수치입니다.

| 지표 | 결과 | 실제 리그 참고값 |
| --- | --- | --- |
| 경기당 득점 | 2.83 | ~2.7 |
| 홈승 / 무 / 원정승 | 44% / 20% / 36% | ~44% / 25% / 31% |
| 경기당 경고 | 1.0 | ~3.5 |
| 경기당 퇴장 | 0.09 | ~0.05 |

무승부 비율이 실제보다 다소 낮습니다. 리그 내 구단 간 전력 차이를 실제 1부 리그보다 넓게
잡아둔 결과로, 강팀과 약팀의 맞대결이 그만큼 일방적으로 끝나기 때문입니다.

이적시장은 별도로 3시즌치를 돌려 불변식을 확인했습니다. 스쿼드 인원 한계, 골키퍼 최소 보유,
예산 음수 방지, 선수가 두 구단에 동시에 존재하지 않는지, 이적 후 선발 명단이 깨지지 않는지를
매 시즌 검사합니다.
