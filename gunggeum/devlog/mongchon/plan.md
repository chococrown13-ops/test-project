# 도시의 나이테 · 원래 ○○이었다 #16 「올림픽공원 잔디 언덕은 원래 백제의 성벽이었다」 — 기획안 (기준일 2026-11-16)

한 줄: 올림픽공원에서 사람들이 산책하고 사진 찍는 잔디 언덕은 그냥 언덕이 아니라 백제 한성 시기에 흙을 쌓아 만든 성벽 「몽촌토성」이다. 88서울올림픽을 앞두고 공원을 만들다 1983~1989년 연합 발굴로 백제 유적임이 확인됐고, 2013년부터 다시 판 북문 안쪽에서는 수레바퀴 자국이 남은 백제 길이 나왔다.
(★ 주제 목록 「올림픽공원 안엔 1,600년 된 성이 있다」에서 다듬음 — 만든 해는 학계 의견이 달라 "1,600년"은 뺌 · 트렌드 카드 trend-20261113 C 와 같은 주제 · 건강·의료 아님)

## 2. 장면표 (30초, 실제 지도 규칙)
- 이름표: 몽촌토성역 · 한성백제역 · 올림픽공원(평화의 문) · 성내천 / 전국 위치 작은 지도 / 북쪽 · 축척(500m) · "지도 © OpenStreetMap 기여자"
- 지도 바탕 명령(제작 때, 좌표는 제작 때 확인): `python3 gunggeum/tools/basemap.py gunggeum/devlog/mongchon/map --center 37.5205,127.1195 --zoom 16 --size 2200x2800 --place "몽촌토성역" --place "한성백제역" --place "평화의 문" --place "성내천" --area "올림픽공원, 송파구, 서울"`
- 이번 편만의 연출(반복 피하기): 카메라가 **성벽 선을 따라 한 바퀴 도는 길**(지난 편 선유도의 옆모습 높이 막대와 다르게). 성벽 자리를 따라 흙빛 굵은 고리가 그려지며 공원 지도 위에 "성"이 드러나요. 색: 지금 = 밝은 지도(`light`), 백제 = 흙빛 고리 + 짙은 갈색 목책 점선 + 청록 해자(성내천), 발굴 = 모눈 네모(발굴 칸) 깜빡임, 2013 길 = 노란 두 줄 바퀴 자국.
- 정확한 옛 성벽 선은 지금 공원의 성벽 언덕 자리(OSM 지형·산책로)를 따라 그리고 "(대략)"을 붙여요.
