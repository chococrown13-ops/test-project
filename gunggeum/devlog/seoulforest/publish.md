# 도시의 나이테 · 원래 ○○이었다 #5 「서울숲은 원래 경마장이었다」

- 영상: `seoulforest.mp4` (30초, 1080×1920, 배경음 코드 생성, 제작비 0원) — 커밋 안 함, 사무실 자료실에 있음
- 만들기: `node capture.cjs <프레임 폴더>` → `python3 audio.py music.wav` → ffmpeg (yeouido 와 같은 방식). 고정 시점(타원 경주로가 숲으로 바뀜).
- 지도는 기록을 바탕으로 단순화한 그림(화면 끝에 표시). 골프장·공사비·승마장 연도는 자료가 한 곳뿐이라 화면에서 뺌.

근거 표는 `plan.md` 참고 (서울시 미디어허브).
