# AI로 운영하는 SNS 계정 전략

사람이 직접 촬영·제작하지 않고, 기획부터 게시물 완성까지 AI 도구로 만드는 SNS 계정 운영 계획입니다.
후보 주제는 **축구 / 세계 여러 나라의 문화 / 동물에 대한 흥미로운 지식 / DIY 미니어처 건물** 네 가지입니다.

- 이 문서: 전략과 주제 선택, 운영 흐름
- [`prompts.md`](prompts.md): Claude에 그대로 붙여 쓰는 프롬프트 템플릿
- [`content-calendar.md`](content-calendar.md): 첫 4주 게시 계획과 주제 아이디어 목록
- [`topics.md`](topics.md): 사실 확인을 마친 주제 목록과 출처
- [`brand.md`](brand.md): 계정 A 「궁금해달」(@otter.curious) 프로필 문구와 캐릭터 설정

## 1. 먼저 알아둘 것: Claude가 하는 일과 다른 도구가 하는 일

Claude는 **글과 기획**을 맡고, 이미지·영상·음성은 생성 전용 도구로 만듭니다.
Claude 혼자서 영상 파일이나 사진 같은 이미지를 만들지는 못합니다.

| 단계 | 담당 | 예시 도구 |
|---|---|---|
| 주제 발굴, 조사, 사실 확인 목록 | Claude | Claude (웹 검색 켜기) |
| 대본, 캡션, 해시태그, 카드뉴스 문구 | Claude | Claude |
| 이미지 생성 프롬프트, 영상 장면 구성(샷 리스트) | Claude | Claude |
| 이미지 생성 | 이미지 생성 AI | Midjourney, GPT Image, Ideogram, Flux 등 |
| 영상 생성 | 영상 생성 AI | Veo, Sora, Kling, Runway 등 |
| 내레이션(TTS) | 음성 AI | ElevenLabs, Typecast, CapCut 내장 TTS 등 |
| 편집, 자막, 음악 | 편집 도구 | CapCut, Vrew |
| 카드뉴스 레이아웃 | 디자인 도구 | Canva, 또는 Claude가 만든 HTML 템플릿을 캡처 |

> 도구는 빠르게 바뀝니다. 위 목록은 출발점일 뿐이니 가격과 상업적 이용 조건(라이선스)을 직접 확인하세요.

## 2. 반드시 지켜야 할 규칙 (계정이 막히거나 수익화가 거절되는 이유)

1. **AI 생성 표시**
   - 유튜브: 사실적으로 보이는 합성 콘텐츠는 업로드할 때 "변경되거나 합성된 콘텐츠" 항목을 체크해야 합니다.
   - 인스타그램·틱톡: AI 생성 콘텐츠 라벨을 켭니다. 프로필 소개에도 "AI로 제작하는 채널"이라고 밝혀두면 좋습니다.
2. **"찍어낸 콘텐츠"는 수익화가 안 됩니다**
   - 유튜브 파트너 프로그램은 대량 생산되거나 반복적인 콘텐츠(같은 틀에 문구만 바꾼 영상, 사람의 해설·편집 가치가 없는 영상)를 수익화 대상에서 제외합니다.
   - 대응: 매 영상마다 **고유한 관점**(비교, 순위, 반전, 질문)을 넣고, 대본을 직접 다듬고, 시리즈 구성을 만드세요. "AI가 만든 것"이 문제가 아니라 "누가 만들어도 같은 결과물"이 문제입니다.
3. **저작권·초상권**
   - 축구 경기 영상, 중계 화면, 구단 엠블럼, 리그 로고는 쓰지 마세요. 저작권 신고 대상입니다.
   - 실존 선수를 AI로 사실처럼 만든 이미지·영상은 초상권 문제와 딥페이크 정책 위반이 될 수 있습니다. 선수는 **일러스트풍·실루엣·등번호**로만 표현하는 편이 안전합니다.
4. **사실 확인**
   - AI는 그럴듯한 오답을 만듭니다. 특히 동물 지식과 문화 콘텐츠는 틀리면 댓글로 바로 지적받고 신뢰를 잃습니다.
   - 모든 대본에 출처 2개 이상을 붙이고, 확인되지 않은 내용은 빼세요. (`prompts.md`의 사실 확인 프롬프트 사용)
5. **고정관념 주의 (문화 주제)**
   - "○○나라 사람들은 다 이렇다"는 식의 일반화는 피하고, "○○ 지역의 전통", "이런 풍습이 있다"처럼 구체적으로 씁니다.

## 3. 주제별 평가

AI 제작(사람 얼굴·촬영 없음) 기준으로 평가했습니다.

| 주제 | AI 제작 적합도 | 성장성 | 위험 요소 | 한 줄 평 |
|---|---|---|---|---|
| 동물 지식 | ★★★★★ | ★★★★ | 사실 오류 | 가장 추천. 짧은 영상에 최적, 전 세계 수요 |
| 세계 문화 | ★★★★ | ★★★★ | 고정관념, 사실 오류 | 추천. 동물 주제와 결이 같아 합치기 좋음 |
| 축구 | ★★★ | ★★★★★ | 저작권, 초상권, 빠른 이슈 주기 | 수요는 가장 크지만 영상화가 까다로움 |
| DIY 미니어처 | ★★ | ★★★ | **진정성 문제** | "DIY"를 AI로 만들면 가짜 제작 영상이 됨 |

### DIY 미니어처는 방향을 바꾸는 것을 권합니다
"직접 만드는 과정"이 핵심인 장르를 AI 영상으로 만들면, 시청자는 실제로 만든 줄 압니다.
들키면 신뢰가 무너지고, 따라 만들려던 사람에게는 쓸모없는 정보가 됩니다. 대신 이렇게 바꿀 수 있습니다.

- **"AI 미니어처 월드"**: 실제 만든 척하지 않고, AI로 만든 미니어처풍(틸트시프트) 건물·도시 이미지를 콘셉트 아트로 보여주기. 예: "세계 랜드마크를 미니어처로 만들면?"
- **문화 주제와 합치기**: "나라별 전통 가옥 미니어처" 시리즈 → 세계 문화 계정의 인기 코너가 될 수 있음
- 나중에 직접 만들 생각이 생기면 그때 실제 제작 채널로 분리

## 4. 추천 계정 구성

네 주제를 한 계정에 섞으면 알고리즘이 "누구에게 보여줄지" 판단하지 못하고, 팔로우할 이유도 흐려집니다.
**계정 두 개로 시작**하는 것을 추천합니다.

### 계정 A (메인): 「궁금해달」 @otter.curious
- 주제: **동물 지식 + 세계 문화 + 미니어처 콘셉트 아트**
- 공통 정체성: "몰랐던 세계의 신기한 사실"
- 플랫폼: 유튜브 쇼츠, 인스타그램 릴스, 틱톡 (같은 세로 영상 1개를 세 곳에 올림) + 인스타 캐러셀(카드뉴스)
- 형식:
  - 30~50초 세로 영상: AI 이미지/영상 + AI 내레이션 + 큰 자막
  - 카드뉴스 6~8장: "알고 계셨나요?" 시리즈
- 코너 예시:
  - `동물 반전 상식` — "사실 ○○는 ○○다"
  - `이 나라에서 하면 안 되는 행동`
  - `세계 이상한 축제`
  - `미니어처로 보는 세계 전통 가옥`
- 장점: 소재가 사실상 무한하고, 유행을 안 타서 오래 조회수가 나옵니다(에버그린). 해외 버전(영어)으로 확장하기 쉽습니다.

### 계정 B (서브): 축구 이야기 계정
- 형식: **글·카드뉴스 중심**으로 시작 (영상은 저작권 부담이 큼)
- 플랫폼: 스레드(Threads), X, 인스타그램 카드뉴스
- 콘텐츠:
  - 경기 전 관전 포인트, 경기 후 한 줄 평 (속도가 생명이라 글이 유리)
  - 축구 규칙·역사 상식: "오프사이드는 왜 생겼을까", "등번호의 유래"
  - 전술 설명: 포메이션 그림은 Claude가 SVG/도식으로 만들 수 있음
  - 이 저장소의 축구 감독 게임(Gaffer) 화면을 활용한 전술 설명도 가능 (직접 만든 것이므로 저작권 문제 없음)
- 주의: 실존 선수 AI 합성 이미지 금지, 루머를 사실처럼 쓰지 않기

## 5. 운영 흐름 (1편 기준 약 40~60분)

```
① 주제 선정 ─ Claude에게 주제 20개 받기 → 3개 고르기
② 조사·사실 확인 ─ Claude(웹 검색)로 근거와 출처 정리, 불확실한 내용 삭제
③ 대본 ─ 첫 2초 훅 → 사실 3개 → 반전/질문으로 마무리 (40초 ≈ 120~140자 x 3단락)
④ 장면 구성 ─ Claude가 장면별 이미지/영상 프롬프트 작성
⑤ 생성 ─ 이미지·영상 생성 → TTS 내레이션
⑥ 편집 ─ CapCut: 자막, 효과음, 배경음악(저작권 없는 음원)
⑦ 게시 ─ Claude가 플랫폼별 제목·캡션·해시태그 작성, AI 라벨 체크
⑧ 회고 ─ 주 1회, 조회수·시청 지속률·저장 수를 Claude에게 붙여넣고 다음 주 계획 받기
```

### 한 번에 몰아서 만들기 (배치 제작)
주말에 2~3시간을 잡고 한 주 분량(영상 5개, 카드뉴스 2개)을 만든 뒤 예약 게시하면 부담이 적습니다.
유튜브·인스타그램·틱톡 모두 예약 게시를 지원하고, Meta Business Suite로 인스타·페이스북을 한 번에 예약할 수 있습니다.

## 6. 게시 주기와 목표

| 기간 | 계정 A | 계정 B | 목표 |
|---|---|---|---|
| 1~4주 | 영상 주 5개 + 카드뉴스 주 2개 | 글 주 3~5개 | 형식 실험, 반응 좋은 코너 찾기 |
| 5~8주 | 반응 좋은 코너 2개에 집중 | 경기일 중심으로 | 영상 평균 시청 지속률 70% 이상 |
| 9~12주 | 시리즈화, 영어 버전 실험 | 카드뉴스 비중 확대 | 팔로워 1,000명, 수익화 조건 점검 |

### 볼 지표
- **시청 지속률 / 끝까지 본 비율**: 짧은 영상에서 가장 중요. 첫 2초에서 많이 이탈하면 훅을 고칩니다.
- **저장·공유 수**: 정보성 계정의 핵심 지표. 좋아요보다 중요합니다.
- **댓글 속 질문**: 다음 콘텐츠 주제의 가장 좋은 출처입니다.

## 7. 비용 대략 (월)

| 항목 | 무료로 시작 | 제대로 운영 |
|---|---|---|
| Claude | 무료 플랜 | Pro 요금제 |
| 이미지 생성 | 무료 크레딧 | 월 1~3만 원대 |
| 영상 생성 | 무료 크레딧(편수 적음) | 월 3~10만 원대 |
| TTS | CapCut 내장 | ElevenLabs 등 유료 |
| 편집 | CapCut 무료 | CapCut Pro |

처음 한 달은 **이미지 + 켄 번스 효과(천천히 확대/이동) + TTS**로 영상을 만들면 영상 생성 AI 없이도 충분합니다.
반응이 확인된 코너에만 영상 생성 크레딧을 쓰세요.
