# 겨울 소원마을 (산타마을 · 해맞이마을) — 시범판

- 미리보기: https://claude.ai/artifact/W3qSR6uWCQ4SkxhecJEitT (claude.ai 아티팩트, 지금은 대표님만 열림)
- 한 파일(`index.html`)에 두 마을. 캔버스 픽셀 그림, 눌러서 이동, 반짝이는 곳에서 행동 버튼.
  - 산타마을: 소원 트리(장식 = 모두의 소원), 산타 우체통(편지는 나만 보기), 썰매 타기, 굴뚝 선물, 모닥불
  - 해맞이마을: 바닷가 전망대(해넘이·해돋이 장면, 평소엔 한국 시간대로 하늘색), 풍등 광장(풍등 = 모두의 소원), 종각(종소리는 같이 있는 사람에게도), 모닥불
- 같이 있기: claude.ai `room`(지금 있는 사람 위치) · 소원 저장: `db` `santa/<사람>` · `sun/<사람>` (한 사람당 마을마다 소원 1개, 다시 쓰면 바뀜) · 편지: `data/users/<사람>/santa-letter`(본인만)
- 글 거르기: 정해진 문구 + 한마디 20자. 욕설·숫자 3개 이상(연락처)·링크는 막음.
- 한계: claude.ai 아티팩트는 로그인한 사람만 소원 저장·같이 있기가 됨. **누구나 들어오는 공개판은 Cloudflare(Workers + Durable Objects)로 옮겨야 함** — 다음 단계.
