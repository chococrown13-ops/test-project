# 궁금해달 스튜디오 — 한 편 만들기

대표(사용자)는 **결재·목소리·업로드**만 합니다. 나머지는 직원들이 합니다.
직원 정의는 `.claude/agents/`, 설정은 `sns/studio.config.json`에 있습니다.

## 0단계 — 출근

- 작업 브랜치 최신화: `git pull`
- `sns/studio.config.json`(예산·모델·결재 방식), `sns/brand.md`, `sns/content-calendar.md`를 읽습니다.
- 다음 편 번호 `epNN`을 정합니다 (`sns/episodes/` 에서 가장 큰 번호 + 1).

## 1단계 — 기획 (리서치)

`research-lead`에게 주제 선정과 사실 확인을 맡깁니다.
대표가 주제를 말했으면 그걸 넘깁니다.

## 2단계 — 대본

`scriptwriter`에게 **판정표 전체**를 넘겨 대본을 받습니다.

## 3단계 — 1차 검수

`quality-guard`에게 **판정표와 대본을 함께** 넘깁니다.
거부되면 고칠 점을 `scriptwriter`에게 돌려보냅니다. 두 번 거부되면 멈추고 대표에게 올립니다.

## 4단계 — 대표 결재 ① 기획안

`studio.config.json`의 `approval`이 `"script"`(기본)이면 **여기서 멈추고** 보고합니다.
돈이 드는 작업(이미지·영상)은 결재 후에만 합니다.

```
📝 EPNN 기획안 — 결재 요청

주제: ○○○ (코너: 반은 맞고 반은 틀려요)
사실 확인: ✅ ○개 · ⚠️ ○개 · ❌ ○개  (❌는 "틀린 반쪽"으로 바로잡음)
대본: (표)
예상 비용: 이미지 ○장 + 영상 ○초 ≈ $○.○ (한도 $○)

승인하시면 "승인"이라고 답해주세요. 고칠 점이 있으면 말씀해주세요.
```

대표가 "끝까지 돌려줘"라고 처음부터 말했거나 `approval`이 `"none"`이면 이 단계를 건너뜁니다.

결재가 나면 `sns/episodes/epNN-<slug>.md`(EP02 형식)와 `sns/episodes/epNN/episode.json`을 만들어 커밋합니다.

## 5단계 — 제작 (동시에)

아래 둘은 서로 기다릴 이유가 없으므로 **한 번에 같이** 띄웁니다.
- `art-director`: 장면 이미지 생성과 1차 점검
- `publisher`: 게시 문구와 체크리스트

이미지가 끝나면 `motion-director`에게 움직일 장면을 고르고 클립을 만들게 합니다.

## 6단계 — 2차 검수

`quality-guard`에게 이미지(파일 경로), 클립 프레임, 게시 문구를 넘깁니다.
거부된 장면은 해당 팀에 돌려보냅니다 (장면당 최대 2번).

## 7단계 — 편집

`editor`에게 미리보기 → 완성본 → 썸네일을 맡깁니다.
완성본과 썸네일은 대표에게 파일로 보냅니다.

## 8단계 — 보고 (대표 결재 ②)

사용자는 개발자가 아닙니다. 쉬운 말로 짧게.

```
🎬 EPNN 완성 — 「제목」

영상: ○○초 (움직이는 장면 S○, S○)  · 썸네일 첨부
검수: 사실 ✅ · 브랜드 ✅ · 게시문구 ✅
이번 편 비용: 약 $○.○ (이미지 ○장, 영상 ○초)

대표님이 하실 일
  1. 목소리 넣기 — 장면 시작 시각: S1 0:00 · S2 0:03 · ...
  2. 업로드 — 게시 문구는 sns/episodes/epNN-<slug>.md 「게시 문구」
  3. AI 라벨 켜기 (유튜브: 변경·합성 콘텐츠 예 / 인스타·틱톡: AI 라벨)
```

마지막으로 `sns/topics.md`와 `sns/content-calendar.md`에 상태를 반영하고 커밋·푸시합니다.

## 지켜야 할 것

- **업로드는 하지 않습니다.** 계정 로그인·게시는 대표가 합니다.
- **CapCut 등 외부 편집 도구는 건드리지 않습니다.**
- 판정표에 없는 사실을 대본·캡션에 넣지 않습니다.
- `budget_usd`를 넘길 것 같으면 멈추고 보고합니다. 한도를 스스로 올리지 않습니다.
- API 오류(잔액 부족, 권한)가 나면 그 단계에서 멈추고 오류 문구를 그대로 보고합니다.
- 검수팀 거부를 다른 팀이 무시하고 넘어가지 않습니다.

## 성과 회의

대표가 조회수·댓글을 붙여주며 "이번 주 성과 봐줘"라고 하면 `growth-analyst`를 부릅니다.
