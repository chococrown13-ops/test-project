# 냉장고 속 회의 1화 다시 짜기 — 방향 3가지 (2026-11-11)

## 왜 다시 짜나 (지금 1화의 문제)
- 첫 30초에 궁금한 게 없음(불 꺼짐 → 출석) → 롱폼은 처음 30초에 가장 많이 나감
- 위기가 3분 30초에야 나옴 → 그 전까지는 "김치가 설명하고 모두가 묻는" 수업
- 서서 말만 함 → 몸개그·소품·움직임이 없음
- AI 목소리는 감정이 평평함 → **상황 자체가 웃겨야** 함

## 세 대본의 공통 규칙
1. **0~15초 안에 사건**: 문이 열리고 거대한 손이 뭔가를 가져가거나, 무언가가 사라짐
2. **걸린 게 있음**: 먹히느냐 / 버려지느냐 / 범인이 누구냐
3. **정보 = 무기**: 정보가 설명으로 나오지 않고, 이기거나 살아남는 **증거**로 나옴
4. **2분 30초쯤 뒤집기 한 번**, 끝은 다음 편으로 잇는 장면
5. **몸개그**: 계란은 흥분하면 굴러감 · 케첩은 소리치면 찍 튐 · 두부는 놀라면 물속으로 쏙 · 문 열리면 다 같이 얼음
6. **반복 개그**: 김치 "익을수록 맛있는 법이지" · 두부 "…저 여기 계속 있었어요" · 케첩 "흔들려야 잘 나오는 법"
7. **댓글 참여**: 끝에 질문 하나(투표·추리)
8. 정보는 이미 확인한 3개만: 소비기한(2023.1.1, 냉장 우유류 2031.1.1) · 계란 10자리 · 문 칸 온도 변화

| | A 서바이벌 | B 법정 | C 탐정 |
|---|---|---|---|
| 한 줄 | 내일 냉장고 파먹기, 누가 먹히나 | 버려질 위기의 우유, 재판이 열린다 | 푸딩이 사라졌다, 범인은 이 안에 있다 |
| 첫 15초 | 손이 반찬통을 끌고 감 | 사람이 우유 날짜를 보고 "흠…" | 빈자리에 숟가락 모양 테두리 |
| 재미 | 절박함·배신·희생 | 말싸움·이의 있음!·반전 증언 | 추리·의심·범인 공개 |
| 시리즈로 | 매화 다른 위기 | 매화 다른 재판 | 매화 다른 사건(사건 파일 #n) |
| 댓글 | "누가 먹힐까?" 투표 | "판결에 찬성?" | "범인은 누구?" 추리 |
| 약점 | 결말이 매번 비슷해질 수 있음 | 말이 많아 화면이 정적이기 쉬움 | 단서 설계가 매화 손이 감 |

**추천: C 탐정.** 처음부터 "범인이 누구지?"라는 질문이 생겨서 끝까지 보게 돼요. 정보가 단서로 자연스럽게 들어가고, 「사건 파일」로 매화 새 사건을 만들기 쉬워요. 댓글 추리도 붙이기 좋아요.
