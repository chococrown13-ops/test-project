# Gaffer

풋볼 매니저 스타일의 축구 감독 시뮬레이션을 모바일 세로 화면에 맞춰 만든 웹 게임입니다.
React + TypeScript + Vite로 작성했고, 서버 없이 브라우저에서 전부 동작합니다.

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/ 로 정적 빌드
```

390×844(아이폰 세로) 기준으로 레이아웃을 잡았습니다. 데스크톱에서는 가운데 520px 폭으로 표시됩니다.

## 게임 내용

- **16개 구단, 30라운드 더블 라운드로빈.** 모든 구단과 선수는 가상입니다.
- **선수단** — 23명 스쿼드, 선발 11명 / 교체 7명. 선수를 탭해 선택하고 다른 선수를 탭하면 자리가
  바뀝니다. 같은 선수를 다시 탭하면 능력치·컨디션·시즌 기록 상세를 봅니다.
- **전술** — 5가지 포메이션(4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2), 팀 성향·템포·압박·패스 길이.
  각 설정은 경기 엔진의 공격/중원/수비 수치에 실제로 반영됩니다.
- **경기** — 1분 단위 시뮬레이션을 텍스트 중계로 실시간 재생합니다. 일시정지 / 1x / 2x / 4x /
  끝까지 건너뛰기, 경기 중 교체(5회)와 전술 변경이 가능합니다.
- **이적시장** — 시즌당 두 번(프리시즌 3라운드, 겨울 2라운드) 열립니다. 다른 구단 선수에게
  금액을 제시해 영입하고, 내 선수를 이적 리스트에 올려 제안을 받습니다. 이적료·주급 상한·
  스쿼드 인원(18~28명)·골키퍼 최소 보유가 모두 제약으로 걸립니다. AI 구단끼리도 거래합니다.
- **시즌 진행** — 순위표, 일정, 득점 순위, 이사회 목표와 중간 평가, 시즌 종료 후 선수 성장·노화·
  은퇴와 유스 충원, 순위에 따른 상금.
- **커스터마이즈** — 리그 이름과 16개 구단 전부의 이름·약칭·색상을 직접 바꿀 수 있습니다.
  시작 화면에서 리그명과 내 구단명을, 게임 중에는 구단 탭에서 언제든 편집합니다.
- **자동 저장** — 진행 상황은 `localStorage`에 저장되고 새로고침하면 이어집니다. 업데이트로
  필드가 추가되어도 기존 세이브는 마이그레이션되어 그대로 이어집니다.

## 구조

```
src/
  game/          엔진 (UI 의존성 없음, 순수 TypeScript)
    types.ts         공용 타입
    rng.ts           시드 기반 난수 (mulberry32)
    names.ts         구단·선수 이름 풀
    formations.ts    포메이션 슬롯과 피치 좌표, 포지션 적합도
    generate.ts      선수/스쿼드/리그/일정 생성, 자동 선발
    ratings.ts       능력치 → 팀 전력 환산, 전술 반영
    commentary.ts    중계 문장 템플릿
    matchEngine.ts   분 단위 경기 시뮬레이션
    league.ts        순위표, 최근 폼
    season.ts        회복/사기/성장/시즌 롤오버
    transfer.ts      이적시장 — 창구, 호가, 제안 평가, AI 거래
    save.ts          localStorage 저장·불러오기 (+ 구버전 마이그레이션)
  store/useGame.ts   zustand 스토어 (엔진과 UI 연결)
  ui/                화면과 컴포넌트
```

엔진(`src/game/`)은 React를 전혀 참조하지 않아서 Node에서 그대로 돌려 밸런스를 검증할 수 있습니다.

## 밸런스

6시즌 1,440경기를 돌려 맞춘 수치입니다.

| 지표 | 결과 | 실제 리그 참고값 |
| --- | --- | --- |
| 경기당 득점 | 2.83 | ~2.7 |
| 홈승 / 무 / 원정승 | 44% / 20% / 36% | ~44% / 25% / 31% |
| 경기당 경고 | 1.0 | ~3.5 |
| 경기당 퇴장 | 0.09 | ~0.05 |

무승부 비율이 실제보다 다소 낮습니다. 리그 내 구단 간 전력 차이를 실제 1부 리그보다 넓게
잡아둔 결과로, 강팀과 약팀의 맞대결이 그만큼 일방적으로 끝나기 때문입니다.

이적시장은 별도로 3시즌치를 돌려 불변식을 확인했습니다. 스쿼드 인원 한계, 골키퍼 최소 보유,
예산 음수 방지, 선수가 두 구단에 동시에 존재하지 않는지, 이적 후 선발 명단이 깨지지 않는지를
매 시즌 검사합니다.

## 현재 없는 것

- 계약 기간과 재계약 협상 (이적료와 주급만 다룹니다)
- 자유계약(FA) 선수, 임대
- 컵 대회, 승격·강등
- 훈련 지시, 스카우팅
