# 도시의 나이테 · 원래 ○○이었다 #2 「여의도는 원래 비행장이었다」 — 기획안 (기준일 2026-10-30)

한 줄: 지금 여의도공원 자리는 1971년까지 비행기가 뜨고 내리던 활주로였다. 활주로가 광장이 되고, 공원이 됐다.

## 사실과 근거
| 화면 | 확인 | 근거 |
|---|---|---|
| 여의도에 일제강점기부터 비행장(간이비행장)이 있었다 | ✅ (개설 연도는 1916/1920 자료가 엇갈려 **화면에 연도를 쓰지 않음**) | 서울시 서울이야기(상전벽해의 여의도), 국가기록원 항공 사진 주제 |
| 1922.12.10 안창남이 금강호로 여의도에서 이륙, 서울 상공 비행. 약 5만 명 관람(보도) | ✅ | 경향신문 「안창남」 기사, 서울시 미디어허브 「여의도 비행장 역사의 터널 속 안창남 이야기」 |
| 광복 뒤 1949년부터 공군기지로 사용, 민간 항공은 김포로 옮김(국내선 1964) | ✅ | 서울시 서울이야기. (국제공항 기능 이전 연도는 자료마다 달라 **화면에 쓰지 않음**) |
| 1968 밤섬 폭파, 그 돌로 윤중제 축조 → 여의도 개발 본격화 | ✅ | 서울신문 서울미래유산(2018-07-05), 서울시 서울이야기 |
| 1971 비행장 폐쇄(공군기지 이전) | ✅ (1971/1972 표기 차이 있어 "1971년 비행장이 문을 닫았다"로만) | 서울시 자료 다수 |
| 활주로 자리에 5·16광장 → 이름 바뀐 여의도광장 | ⚠️ 착공·완공 1971 / 조성 1972 자료 엇갈림 → **연도 없이 "그 자리에 광장"** | 서울기록원 여의도광장 항목, 서울신문 |
| 1999 여의도공원 개장 | ✅ 연도 일치 (1.24/7.5 날짜 엇갈림 → **연도만**) | 서울시 공원 안내, 서울기록원 |
